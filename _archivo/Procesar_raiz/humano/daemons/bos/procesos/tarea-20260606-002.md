## Principios transversales — IRRENUNCIABLES en TODAS las fases

Estos principios aplican a CADA pantalla, CADA función, CADA línea de código.
No son opcionales ni negociables.

### P-T1: El terminal manda — 100% del ancho siempre


**`safeW()` debe eliminarse o retornar `m.width` sin descuento.**
Toda función que use `sw` debe reemplazarlo por `m.width` o la proporción exacta del doc.

### P-T2: El body siempre es viewport.Model — sin excepciones (§0 del doc)


### P-T3: recalcBodyHeight() correcto (§0 del doc, líneas 56-64)


### P-T4: Centrado vertical del contenido

Cuando el contenido del body es más corto que `bodyHeight`:
```go

func (m model) viewFullLog() string {
    // toolbar: filtros + contador
    filterLabels := []string{"Todos", "✓ OK", "⚠ Advertencias", "✗ Errores"}
    var tbParts []string
    for i, lbl := range filterLabels {
        style := sDim
        if LogLevel(i) == m.logFilter { style = sBold.Copy().Foreground(cCyan) }
        tbParts = append(tbParts, style.Render(lbl))
    }
    filtered := m.filteredLogs()
    counter  := sDim.Render(fmt.Sprintf("%d líneas", len(filtered)))
    toolbar  := strings.Join(tbParts, " │ ") + "  " + counter

    // búsqueda
    searchLine := sDim.Render("/ buscar...")
    if m.logSearch != "" {
        searchLine = "/ " + sCyan.Render(m.logSearch)
    }

    // viewport ocupa resto del body
    vp := m.vpLog
    vp.Height = m.bodyHeight - 2  // -2 por toolbar+search
    vp.Width  = m.width

    var lines []string
    for _, e := range filtered {
        line := e.render(m.width)
        // resaltar match con fondo #0e3a1a
        if m.logSearch != "" && strings.Contains(e.Msg, m.logSearch) {
            line = lipgloss.NewStyle().Background(lipgloss.Color("#0e3a1a")).Render(line)
        }
        lines = append(lines, line)
    }
    vp.SetContent(strings.Join(lines, "\n"))
    return lipgloss.JoinVertical(lipgloss.Left, toolbar, searchLine, vp.View())
}
```

```go
    // Toolbar línea 1: Nivel

    // Toolbar línea 2: Fuente
    fuenteLabels := []string{"Todas", "bos", "k8s", "sistema"}
    // Toolbar línea 3: búsqueda + autoScroll
    searchLine := sDim.Render("/ buscar...")
    if m.logSearch != "" { searchLine = "/ " + sCyan.Render(m.logSearch) }
    autoStr := sDim.Render("[↓ auto]")
    if m.logAutoScroll { autoStr = sBold.Render("[↓ auto]") }

        ts     := sDim.Render(e.Ts)

        nivelToolbar,
```
