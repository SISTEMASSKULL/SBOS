# bAuthDEV — RPC Tester para Desarrolladores SBOS

[![Download Windows](https://img.shields.io/badge/Descargar-Windows%20x64-blue?style=for-the-badge&logo=windows)](https://github.com/SISTEMASSKULL/skproject-sbos/releases/latest)

## Que es

Herramienta de escritorio para probar, aprender e integrar **bAuth** en tus proyectos.
Conecta al daemon real, explora 47+ metodos JSON-RPC, prueba tokens, firma digital
y blockchain. Copia codigo listo para Go, Python, Rust, JS, PHP y cURL.

## Instalacion

1. Ve a [Releases](https://github.com/SISTEMASSKULL/skproject-sbos/releases/latest)
2. Descarga `bAuthDEV-windows-x64.zip`
3. Descomprime y ejecuta `bauth_dev.exe`

**Sin instalador. Sin dependencias.** Solo descargar y ejecutar.

## Actualizar

Descarga la nueva version y descomprime sobre la carpeta anterior.
