# 2.18 — Motor de Comunicación: banexus-implicit
## Protocolo de apps de software → bhnexus (que enruta a bAuth)

**Versión:** 4.0.0
**Fecha:** 2026-08-06
**Fase del ciclo:** 2 — PROTECCIÓN
**Depende de:** 2.12 (Canales Protegidos) · 2.03 (Tokens) · 2.01 (Autenticación)
**Fuente de verdad de formas:** `BnexusAgent/1.06_MANUAL-FORMAS-BANEXUS.md` §4
**Motor ADR-013:** Canales (transportar) — superficie banexus-implicit
**Estado:** ⬜ L0 — especificación correcta · implementación Rust SDK de referencia en `BauthAgent/src/bnexus/banexus/sdk/`

---

## 0. Principio rector

> **Todo pasa por bhnexus. Nadie habla directamente con bAuth.**
> banexus-implicit es la forma que toman las apps de software: se conectan a bhnexus,
> bhnexus valida la identidad con bAuth y enruta la petición.

Las aplicaciones de software (Flutter, Laravel, React, Django, Rust M2M) no se conectan a bAuth directamente. Se conectan a **bhnexus** en el puerto **9444**, que actúa como broker y enruta las peticiones a bAuth a través de la Puerta 2.

Esta regla es absoluta:

```
❌  app → bAuth        (saltar bhnexus = perder routing, cache y auditoría)
✅  app → bhnexus → bAuth
```

*(Ref: `BnexusAgent/1.01_MANUAL-TOPOLOGIA-NEXUS.md` §4 — topología invariable)*

---

## 1. Los tres protocolos de banexus-implicit

| Protocolo | Estándar | Responsabilidad |
|-----------|---------|----------------|
| **JWT / OIDC** | RFC 6749 + 7519 | La app presenta su JWT al handshake con bhnexus — bhnexus valida contra bAuth JWKS |
| **rpc_call / rpc_response** | JSON-RPC 2.0 sobre frames bNexus | Envoltura de peticiones JSON-RPC que bhnexus enruta a bAuth |
| **W3C Trace Context** | W3C + OTel | ctx_id propagado en cada frame para trazabilidad y auditoría |

---

## 2. El transporte: newline-delimited JSON sobre TCP / WebSocket

### 2.1 Por qué este protocolo

bhnexus ya habla este protocolo en su Puerta 1 con banexus-daemon y banexus-gateway. banexus-implicit usa el mismo canal (puerto 9444) con una variante de autenticación: **JWT en lugar de SPIFFE/SVID**.

| Modo | Transporte | Autenticación |
|------|-----------|---------------|
| Desarrollo (`dev_mode = true`) | TCP plano, newline-delimited JSON | `dev_mode: true` en handshake |
| Producción | WebSocket TLS 1.3 (rustls), newline-delimited JSON | JWT válido emitido por bAuth |

### 2.2 El protocolo de wire

```
App                                   bhnexus:9444
 │                                        │
 │── TCP connect ───────────────────────►│
 │                                        │
 │── {"type":"handshake",                │
 │    "node_id":"mi-app-desktop",        │
 │    "jwt":"eyJ...",                    │
 │    "modo":"proxy"}\n ───────────────►│
 │                                        │  bhnexus valida JWT con bAuth JWKS
 │◄── {"type":"handshake_ok",            │
 │     "node_id":"<UUID-asignado>",      │
 │     "granted":true}\n ───────────────│
 │                                        │
 │── {"type":"rpc_call",                 │
 │    "payload":{                         │
 │      "jsonrpc":"2.0",                 │
 │      "method":"bauth.health.check",   │
 │      "params":{},                     │
 │      "id":1},                         │
 │    "seq":1}\n ──────────────────────►│
 │                                        │  bhnexus enruta a bAuth via Puerta 2
 │◄── {"type":"rpc_response",            │
 │     "payload":{                        │
 │       "jsonrpc":"2.0",                │
 │       "result":{"status":"operativo"},│
 │       "id":1},                         │
 │     "seq":1}\n ──────────────────────│
```

Spec completa de wire: `BnexusAgent/anexos/A.02_PROTOCOLO-WIRE-PUERTA-1.md`

### 2.3 Endpoints por entorno

| Entorno | Host bhnexus | Puerto | TLS |
|---------|-------------|--------|:---:|
| Desarrollo local | `127.0.0.1` | `9444` | No |
| Desarrollo remoto (VPS) | `13.140.128.230` | `9444` | No (dev_mode) |
| Producción | `bhnexus.sbos.local` | `9444` | TLS 1.3 |

> **NUNCA** conectar a bAuth puerto 9450 desde una app cliente.
> Ese puerto es exclusivo para la comunicación Puerta 2 (bhnexus → bAuth).

## 3. El contrato de transporte — agnóstico de lenguaje

```
interfaz ITransporte {
  conectar(bhnexus_uri: string, node_id: string, jwt: string) → Promise<void>
  llamar(metodo: string, params: objeto) → Promise<objeto>
  desconectar()                          → void
  estaConectado()                        → bool
  onEvento(tipo: string, handler: fn)   → void  // para server push CAEP
}
```

Propiedades que toda implementación debe cumplir:

- **Multiplexado por seq:** N peticiones correlacionadas por campo `seq`
- **Reconexión automática:** backoff exponencial (1s → 5s → 15s → 30s → 60s)
- **Renovación de token:** si JWT expira en < 5 min, renovar y re-handshake
- **ctx_id propagado:** campo `ctx_id` (W3C traceparent) en cada rpc_call
- **Timeout por llamada:** 30s por defecto

### 4.1 TypeScript — React / Vue / Node.js

```typescript
// sdk/bauth-nexus-client.ts — funciona en React, Vue, Angular, Node.js, Deno
// Conecta a bhnexus:9444, NO a bAuth directamente.

import * as net from 'net';  // Node.js; en browser usar WebSocket TLS

class BauthNexusTransporte {
  private socket: net.Socket | null = null;
  private buffer = '';
  private pendientes = new Map<number, {
    resolve: (v: unknown) => void;
    reject:  (e: Error)   => void;
  }>();
  private nextSeq = 1;

  async conectar(bhnexusAddr: string, nodeId: string, jwt: string): Promise<void> {
    const [host, port] = bhnexusAddr.split(':');
    this.socket = net.createConnection({ host, port: Number(port) });

    await new Promise<void>((res, rej) => {
      this.socket!.once('connect', () => {
        this.enviarLinea({ type: 'handshake', node_id: nodeId, jwt, modo: 'proxy' });
      });
      this.socket!.once('error', rej);
      this.socket!.on('data', (chunk) => {
        this.buffer += chunk.toString();
        const lines = this.buffer.split('\n');
        this.buffer = lines.pop()!;
        for (const line of lines) {
          if (!line.trim()) continue;
          const msg = JSON.parse(line);
          if (msg.type === 'handshake_ok' && msg.granted) { res(); }
          else if (msg.type === 'rpc_response')            { this.onRespuesta(msg); }
        }
      });
    });
  }

  async llamar(metodo: string, params?: Record<string, unknown>): Promise<unknown> {
    const seq = this.nextSeq++;
    return new Promise((resolve, reject) => {
      this.pendientes.set(seq, { resolve, reject });
      this.enviarLinea({
        type:    'rpc_call',
        payload: { jsonrpc: '2.0', method: metodo, params: params ?? {}, id: seq },
        seq,
      });
      setTimeout(() => {
        if (this.pendientes.has(seq)) {
          this.pendientes.delete(seq);
          reject(new Error(`Timeout en ${metodo}`));
        }
      }, 30_000);
    });
  }

  private onRespuesta(msg: { seq: number; payload: { result?: unknown; error?: { message: string } } }) {
    const cb = this.pendientes.get(msg.seq);
    if (!cb) return;
    this.pendientes.delete(msg.seq);
    msg.payload.error
      ? cb.reject(new Error(msg.payload.error.message))
      : cb.resolve(msg.payload.result);
  }

  private enviarLinea(obj: unknown) { this.socket?.write(JSON.stringify(obj) + '\n'); }
  desconectar() { this.socket?.destroy(); }
}

// Uso:
const cliente = new BauthNexusTransporte();
await cliente.conectar('13.140.128.230:9444', 'mi-app-react', tokenJwt);
const resultado = await cliente.llamar('bauth.health.check', {});
```

### 4.2 PHP — Laravel / Symfony

```php
<?php
// app/Services/BauthNexusTransporte.php
// Conecta a bhnexus:9444, NO a bAuth directamente.

namespace App\Services;

class BauthNexusTransporte
{
    private $socket = null;
    private int $nextSeq = 1;

    public function conectar(string $bhnexusAddr, string $nodeId, string $jwt): void
    {
        [$host, $port] = explode(':', $bhnexusAddr);
        $this->socket = stream_socket_client("tcp://{$host}:{$port}", $errno, $errstr, 5);
        if (!$this->socket) {
            throw new \RuntimeException("No se pudo conectar a bhnexus: {$errstr}");
        }
        $this->enviarLinea(['type' => 'handshake', 'node_id' => $nodeId, 'jwt' => $jwt, 'modo' => 'proxy']);
        $ack = json_decode($this->leerLinea(), true);
        if (!($ack['granted'] ?? false)) {
            throw new \RuntimeException('Handshake rechazado por bhnexus');
        }
    }

    public function llamar(string $metodo, array $params = []): mixed
    {
        $seq = $this->nextSeq++;
        $this->enviarLinea([
            'type'    => 'rpc_call',
            'payload' => ['jsonrpc' => '2.0', 'method' => $metodo, 'params' => $params, 'id' => $seq],
            'seq'     => $seq,
        ]);
        $resp = json_decode($this->leerLinea(), true);
        if (isset($resp['payload']['error'])) {
            throw new \RuntimeException($resp['payload']['error']['message']);
        }
        return $resp['payload']['result'];
    }

    private function enviarLinea(array $data): void { fwrite($this->socket, json_encode($data) . "\n"); }
    private function leerLinea(): string             { return trim(fgets($this->socket, 65536)); }
}

// config/bauth.php
return [
    'bhnexus_addr' => env('BHNEXUS_ADDR', '13.140.128.230:9444'),
    'app_node_id'  => env('BAUTH_NODE_ID', 'laravel-app'),
];
```

### 4.3 Dart — Flutter (desktop, mobile, web)

> **Implementación de referencia:** `BauthAgent/src/bnexus/banexus/sdk/` (`lib.rs` + `protocolo.rs`).
> En Flutter desktop, la DLL Rust (`banexus.dll`) encapsula exactamente esta lógica via FFI.
> La clase `BanexusCliente` en `lib/libs/bauth_nexus/cliente.dart` la usa correctamente.
> El código siguiente es la versión pura Dart para entornos sin FFI (ej. Flutter Web).

```dart
// lib/nucleo/comunicacion/bauth_nexus_transporte.dart
// Conecta a bhnexus:9444, NO a bAuth directamente.

import 'dart:async';
import 'dart:convert';
import 'dart:io';

class BauthNexusTransporte {
  Socket? _socket;
  String  _buffer = '';
  final _pendientes = <int, Completer<Map<String, dynamic>>>{};
  int _nextSeq = 1;

  /// Conecta a bhnexus (port 9444) y hace handshake banexus-implicit.
  Future<void> conectar(String bhnexusAddr, String nodeId, String jwt) async {
    final parts = bhnexusAddr.split(':');
    _socket = await Socket.connect(parts[0], int.parse(parts[1]),
        timeout: const Duration(seconds: 5));

    final ackCompleter = Completer<void>();
    _socket!.listen((data) {
      _buffer += utf8.decode(data);
      final lineas = _buffer.split('\n');
      _buffer = lineas.removeLast();
      for (final linea in lineas) {
        if (linea.trim().isEmpty) continue;
        final msg = jsonDecode(linea) as Map<String, dynamic>;
        if (msg['type'] == 'handshake_ok') {
          msg['granted'] == true
            ? ackCompleter.complete()
            : ackCompleter.completeError(Exception('Handshake rechazado por bhnexus'));
        } else if (msg['type'] == 'rpc_response') {
          _onRespuesta(msg);
        }
      }
    });

    _enviarLinea({'type': 'handshake', 'node_id': nodeId, 'jwt': jwt, 'modo': 'proxy'});
    await ackCompleter.future.timeout(const Duration(seconds: 10));
  }

  Future<Map<String, dynamic>> llamar(String metodo, [Map<String, dynamic>? params]) {
    final seq = _nextSeq++;
    _enviarLinea({
      'type': 'rpc_call',
      'payload': {'jsonrpc': '2.0', 'method': metodo, 'params': params ?? {}, 'id': seq},
      'seq': seq,
    });
    final c = Completer<Map<String, dynamic>>();
    _pendientes[seq] = c;
    return c.future.timeout(const Duration(seconds: 30),
        onTimeout: () => throw TimeoutException('Timeout en $metodo'));
  }

  void _onRespuesta(Map<String, dynamic> msg) {
    final cb = _pendientes.remove(msg['seq'] as int?);
    if (cb == null) return;
    final payload = msg['payload'] as Map<String, dynamic>;
    final err = payload['error'];
    err != null
      ? cb.completeError(Exception(err['message']))
      : cb.complete((payload['result'] as Map<String, dynamic>?) ?? {});
  }

  void _enviarLinea(Map<String, dynamic> obj) => _socket?.write('${jsonEncode(obj)}\n');
  void desconectar() => _socket?.destroy();
}
```

### 4.4 Rust — daemons M2M (biedata, bnotify, bsearch → bAuth)

```rust
// src/transport/bauth_nexus_cliente.rs
// Para daemons hermanos que llaman a bAuth vía bhnexus (M2M).
// Conecta a bhnexus:9444, NO a bAuth directamente.

use serde_json::{json, Value};
use tokio::io::{AsyncBufReadExt, AsyncWriteExt, BufReader};
use tokio::net::TcpStream;

/// Cliente M2M para daemons SBOS que necesitan llamar a bAuth.
pub struct BauthNexusCliente {
    pub bhnexus_addr: String,
    pub node_id:      String,
    pub jwt:          String,  // token M2M (client_credentials), renovar periódicamente
}

impl BauthNexusCliente {
    /// Ejecuta una llamada JSON-RPC a bAuth a través de bhnexus.
    pub async fn llamar(
        &self,
        metodo:  &str,
        params:  Value,
        ctx_id:  &str,
    ) -> anyhow::Result<Value> {
        let stream = TcpStream::connect(&self.bhnexus_addr).await?;
        let (reader, mut writer) = stream.into_split();
        let mut lines = BufReader::new(reader).lines();

        // Handshake banexus-implicit con JWT de daemon
        let hs = json!({
            "type":    "handshake",
            "node_id": self.node_id,
            "jwt":     self.jwt,
            "modo":    "proxy",
        });
        writer.write_all(format!("{}\n", hs).as_bytes()).await?;

        let ack_line = lines.next_line().await?
            .ok_or_else(|| anyhow::anyhow!("bhnexus cerró sin ACK"))?;
        let ack: Value = serde_json::from_str(&ack_line)?;
        if ack["granted"] != true {
            anyhow::bail!("handshake rechazado por bhnexus");
        }

        // rpc_call con ctx_id para trazabilidad (SBOS-049)
        let seq = 1u64;
        let call = json!({
            "type": "rpc_call",
            "payload": {
                "jsonrpc": "2.0",
                "method":  metodo,
                "params":  params,
                "id":      seq,
                "ctx_id":  ctx_id,
            },
            "seq": seq,
        });
        writer.write_all(format!("{}\n", call).as_bytes()).await?;

        let resp_line = lines.next_line().await?
            .ok_or_else(|| anyhow::anyhow!("sin respuesta de bhnexus"))?;
        let resp: Value = serde_json::from_str(&resp_line)?;
        if let Some(err) = resp["payload"]["error"].as_object() {
            anyhow::bail!("Error bAuth: {}", err["message"].as_str().unwrap_or("?"));
        }
        Ok(resp["payload"]["result"].clone())
    }
}
```

### 4.5 Python — Django / FastAPI

```python
# bauth/nexus_transporte.py — agnóstico de framework (Django, FastAPI, Flask)
# Conecta a bhnexus:9444, NO a bAuth directamente.
import json
import socket

class BauthNexusTransporte:
    def __init__(self, bhnexus_addr: str, node_id: str, jwt: str):
        host, port_str = bhnexus_addr.split(':')
        self._sock = socket.create_connection((host, int(port_str)), timeout=5)
        self._file = self._sock.makefile('rb')
        self._next_seq = 1

        # Handshake banexus-implicit
        self._enviar({'type': 'handshake', 'node_id': node_id, 'jwt': jwt, 'modo': 'proxy'})
        ack = self._leer()
        if not ack.get('granted'):
            raise RuntimeError(f'Handshake rechazado por bhnexus: {ack}')

    def llamar(self, metodo: str, params: dict | None = None) -> dict:
        seq = self._next_seq
        self._next_seq += 1
        self._enviar({
            'type': 'rpc_call',
            'payload': {'jsonrpc': '2.0', 'method': metodo, 'params': params or {}, 'id': seq},
            'seq': seq,
        })
        resp = self._leer()
        payload = resp.get('payload', {})
        if 'error' in payload:
            raise RuntimeError(f"bAuth error: {payload['error']['message']}")
        return payload.get('result', {})

    def _enviar(self, obj: dict) -> None:
        self._sock.sendall((json.dumps(obj) + '\n').encode())

    def _leer(self) -> dict:
        return json.loads(self._file.readline().decode().strip())

    def cerrar(self) -> None:
        self._sock.close()
```

## 5. Sagas del motor de comunicación

### 5.1 Saga de conexión

```
PASO 1: Obtener JWT válido
  → IRepositorioTokens.tokenValido() / obtener token de bAuth OIDC
  ✓ Token vigente con exp > now + 5min

PASO 2: Conectar a bhnexus:9444 y hacer handshake
  → TCP connect a bhnexus (dev) / WebSocket TLS a bhnexus (prod)
  → Enviar {"type":"handshake","node_id":"<app-id>","jwt":"<token>","modo":"proxy"}
  ← {"type":"handshake_ok","granted":true,"node_id":"<uuid-asignado>"}
  ✗ granted:false → JWT inválido → compensar: renovar token + reintentar
  ✗ TCP refused  → bhnexus no disponible → compensar: backoff exponencial

PASO 3: Verificar canal
  → llamar("bauth.health.check", {}) → { "status": "operativo" }
  ✓ Canal activo — bhnexus enruta a bAuth
  ✗ Timeout 5s  → compensar: cerrar + volver a PASO 2

RESULTADO: canal listo para operación
```

### 5.2 Saga de reconexión

```
EVENTO: Conexión TCP/WS cerrada inesperadamente (red, restart bhnexus)

PASO R1: Detectar cierre (EOF o error de lectura)

PASO R2: Backoff exponencial
  → 1s → 5s → 15s → 30s → 60s (indefinidamente cada 60s)

PASO R3: Re-ejecutar Saga de conexión completa
  → Si JWT expiró durante el intento: renovar antes del handshake

COMPENSACIÓN (sin bhnexus por > 4h):
  → Apps con Policy Cache local (banexus-daemon/gateway): operar offline
  → Apps sin cache: mostrar "Sin conexión" y reintentar
```

### 5.3 Saga de renovación de token

```
EVENTO: exp del JWT < now + 5min

PASO T1: Renovar via refresh_token (bAuth OIDC endpoint)
PASO T2: Persistir nuevo token (SecureStorage / cache cifrado)
PASO T3: Re-handshake con bhnexus usando nuevo JWT
  → Cerrar conexión TCP/WS actual
  → Reconectar con nuevo token (Saga conexión completa)
```

### 5.4 Saga de logout / revocación CAEP

```
EVENTO: logout del usuario, o bAuth emite evento CAEP session_ended

PASO V1: Notificar a bhnexus
  → llamar("bauth.session.logout", { "jti": "<jti_activo>" })
  ← { "ok": true }

PASO V2: Cerrar conexión TCP/WS con bhnexus
PASO V3: Limpiar tokens locales (SecureStorage)
```

## 6. Normas irrenunciables

| Norma | Restricción |
|-------|------------|
| **Topología bNexus** | NUNCA conectar a bAuth puerto 9450 desde una app — ese puerto es exclusivo Puerta 2 (bhnexus↔bAuth) |
| SBOS-050 P9 | NUNCA HTTP/TCP directo entre daemons hermanos — solo Unix socket |
| ADR-020 | Interface Dual: `/run/bos/bauth.sock` para Puerta 2 daemon; TCP/WS 9444 para clientes via banexus-implicit |
| RFC 6455 | WebSocket estándar en producción — TCP plano solo aceptable en `dev_mode = true` |
| NIST SP 800-63B | Canal TLS 1.3 obligatorio en producción |
| SBOS-049 | `ctx_id` inyectado en cada rpc_call — propagado por toda la operación |
| ISO 27001 A.8.20 | Todo canal auditado — ctx_id presente en toda respuesta bhnexus→app |
