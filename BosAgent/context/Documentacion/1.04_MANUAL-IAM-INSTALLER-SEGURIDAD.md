## 1. Principio rector — Superficie Mínima de Ataque

> **Cada endpoint, puerto y protocolo que un daemon expone es un vector de ataque.
> Lo que no existe no puede ser atacado.**

Antes de implementar cualquier comunicación: ¿es absolutamente necesaria? ¿puede resolverse
con un canal ya existente? ¿cuál es la superficie mínima?

---

## 2. Modelo de amenazas STRIDE

| Categoría | Amenaza | Control |
|-----------|---------|---------|
| Spoofing | Suplantar identidad de daemon | mTLS con certs Vault PKI (NRS-03) |
| Tampering | Modificar respuesta de Context API | TLS 1.3 en :9443 (NRS-01) |
| Repudiation | Negar operación realizada | audit_event con ctx_id (NRS-09) |
| Information Disclosure | Leer ctx_id de logs | Sanitización (SAN-07) |
| Denial of Service | Saturar Context API | Rate limiting 100 req/s (NRS-08) |
| Elevation of Privilege | Acceder a tenant ajeno | Cross-tenant validation (SAN-04) |

## 3. Reglas NRS (Network Security Rules)

| # | Regla | Estado |
|:-:|-------|:------:|
| NRS-01 | TLS 1.3 en :9443, cipher ECDHE+AES-256-GCM+SHA384, `tls.Config.MinVersion = tls.VersionTLS13` | ❌ |
| NRS-02 | Sin HTTP entre daemons — solo Unix sockets (SBOS-050 P9) | ✅ |
| NRS-03 | mTLS para Kong→BOS: `tls.Config.ClientAuth = tls.RequireAndVerifyClientCert` | ❌ |
| NRS-04 | NetworkPolicy deny-all + allowlist explícita por namespace | ❌ |
| NRS-05 | TLS 1.3 en todos los endpoints externos | ❌ |
| NRS-06 | DTOs separados de domain models — `omitempty` en campos no esenciales | ❌ |
| NRS-07 | Anti-enumeration: respuesta idéntica para "no encontrado" y "expirado" | ❌ |
| NRS-08 | Rate limiting 100 req/s por IP (token bucket), response 429 | ❌ |
| NRS-09 | Prometheus security metrics + audit log por cada validación de ctx_id | ❌ |
| NRS-10 | CI: gosec (zero HIGH) + govulncheck + gitleaks bloqueante en PR | ❌ |

## 4. Reglas SAN (Sanitization)

SAN-01..SAN-12: paquete `internal/sanitize/` centralizado. UUIDv4, Slug, Email, IPAddr,
FilePath, JSONPayload, HeaderValidate, truncate. Cero dependencias externas. Tests ≥ 90%.
**Sin implementar.**

SAN-07 (crítica): nunca loguear `session_kc`, `user_id` completo, tokens o secretos.
`logSanitize(ctxID)`: solo primeros 8 chars + hash.

## 5. Firewall — UFW deny-all

Solo 22 (SSH) y 443 (Kong/nginx S16) abiertos al exterior. Todo lo demás: ClusterIP o localhost.
