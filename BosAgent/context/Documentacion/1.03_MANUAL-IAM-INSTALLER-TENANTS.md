## 3. Aislamiento multi-tenant

| Recurso | Mecanismo |
|---------|-----------|
| K8s | Namespace por tenant + NetworkPolicy default-deny + ResourceQuota |
| PostgreSQL | Un schema por daemon en SBOS_db + BD independiente por app |
| Keycloak | Un realm por tenant |
| Vault | Path `secret/tenants/{tenant}/` con AppRole por ficha |
| Redis | DB1 con prefijo `{tenant}:` en keys |
| Contexto | ctx_id con tenant_id — cross-tenant validation |
