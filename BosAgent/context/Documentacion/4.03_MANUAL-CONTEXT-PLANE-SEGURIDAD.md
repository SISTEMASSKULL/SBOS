## 1. UUID v4 estricto
Regex validación en todos los endpoints. Anti-injection. SAN-09.

## 2. Anti-enumeration
Respuesta idéntica para "no encontrado" y "expirado". Mismo HTTP status, misma latencia.

## 3. Rate Limiting
Token bucket 100 req/s por IP. Response 429 con retry_after_s.

## 4. Sanitización de logs
ctx_id → solo primeros 8 chars + hash. session_kc nunca en logs. ISO 27001 A.8.15.

## 5. Cross-tenant validation
Verificar que tenant_id del request coincide con tenant_id del ctx_id.
