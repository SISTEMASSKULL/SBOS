# Manual de Integración bAuth — Motor Context Plane
## bos.ctx.resolve → /run/bos/bauth.sock → 12 dominios → Redis cache (fortalece 4.01)

**Versión:** 1.0.0 · **Fecha:** 2026-07-17 · **Autor:** bos-developer — SBOS
**Motor:** ④ Context Plane · **Rol:** Fortalece [4.01](4.01_MANUAL-CONTEXT-PLANE.md)
**Estado:** L1 — cliente existe, server-side es de bAuth

---

## 1. Flujo de integración

```
BOS recibe request → bos.ctx.resolve(ctx_id)
  → JSON-RPC bauth.context.evaluate sobre /run/bos/bauth.sock
  → bAuth evalúa 12 dominios (D1-D12) contra el RolTemplate del usuario
  → retorna DomainResult con la decisión de cada dominio
  → BOS cachea en Redis DB1 (TTL 30s)
```

## 2. Lo que existe y lo que falta

- **Cliente bAuth en BOS:** `internal/bauth/client.go` — CreateCtx, PromoteCtx, EvaluateContext. OK.
- **Servidor bAuth:** implementación del lado de BauthAgent, no de BosAgent.
- **Falta:** Context Plane operativo (F5) para que el flujo funcione end-to-end.
