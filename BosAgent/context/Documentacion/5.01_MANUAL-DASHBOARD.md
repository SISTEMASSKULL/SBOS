## 1. Interface Dual (ADR-019/020)

```
/run/bos/bos.sock (0660, grupo bosagent)
  ├── Vía 1: WebSocket RPC → bosctl CLI, dashboard externo (bAuth)
  └── Vía 2: JSON-RPC 2.0 → daemons (bauth...), scripts, agentes IA
```

**Sin HTTP/TCP entre daemons** (SBOS-050 P9). El socket Unix es el ÚNICO canal. Toda la
información del BOS está disponible vía JSON-RPC para ser consumida por el dashboard de bAuth.
Cualquier feature nuevo sigue el patrón: `domain/<servicio>.go` → `server/jsonrpc.go` → `cmd/bosctl/<cmd>.go`.

### 2.1 Auth, timeouts, batch

- **Auth:** token compartido (`/etc/bos/rpc-token`) para métodos destructivos. Sin token → -32600.
- **Timeouts:** 5s lectura, 30s escritura, 600s sagas. `runWithTimeout` con canal buffer 1.
- **Batch:** `dispatchBatch` — goroutine por solicitud, orden preservado, notificaciones omitidas.
- **Errores:** -32001 (context expired), -32005 (not found), -32006 (timeout), -32007 (invalid state).
