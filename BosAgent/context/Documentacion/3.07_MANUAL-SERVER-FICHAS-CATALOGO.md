## 1. Principio R7 — todo daemon es ficha (A.02 §2.2)

Cada daemon del ecosistema SBOS (bauth, bnotify, bkernel, biedata, bsearch, bi18n, bnexus)
es una ficha instalada por el BOS. El BOS es el único instalador — ningún daemon se instala
manualmente con `systemctl`, `apt`, o scripts externos.

```
bosctl ficha install bauth    ← correcto
sudo systemctl start bauth    ← PROHIBIDO (viola ADR-022)
```

### S16-webserver — Web multi-tenant (A.03 v3.0.0)

Servidor independiente de S02. Tiene su propio namespace `sbos-web`.
Gestiona dominios a través de `bos.web.domain.*` JSON-RPC y tabla `bos.net_web_domain` (T-415).

| Ficha | Estado | Función |
|-------|:------:|---------|
| `nginx` | 🔴 | Reverse proxy multi-tenant · genera conf por dominio desde `bos.net_web_domain` |
| `certbot` | 🔴 | TLS automático ACME/Let's Encrypt · timer systemd cada 12h · RFC 8555 |
| `modsecurity` | 🔴 | WAF con OWASP Core Rule Set · DDoS/SQLi/XSS |
| `website-engine` | 🔴 | Renderizado multi-tenant: headers `X-SBOS-Tenant` `X-SBOS-Empresa` `X-SBOS-Sucursal` |

**3 tipos de web gestionados por nginx:**

| Tipo | Dominio ejemplo | Dónde vive |
|------|----------------|-----------|
| Institucional | `skull.sbos.app` | S16-webserver |
| Tenant | `empresa1.sbos.app` | S16-webserver → enruta a S04-S11 |
| Sucursal | `norte.empresa1.sbos.app` | S16-webserver → enruta por tenant+sucursal |

## 4. Anatomía obligatoria de cada ficha (A.05)

```
servers/<servidor>/<nombre-ficha>/
├── manifest.yml      ← OBLIGATORIO: identidad, deps, servidor, namespace, puerto, health
├── PROPOSITO.md      ← OBLIGATORIO: qué es, por qué, para qué (Bibliotecario rechaza sin él)
├── task_catalog.sh   ← OBLIGATORIO: 5 funciones: <app>_install/_verify/_health/_repair/_remove
└── resources/        ← opcional: sql/, config/, k8s.yml, vault/, migrations/
```

**Regla de idempotencia (SOV-04):** `<app>_install()` ejecutado 2 veces produce el mismo resultado.
