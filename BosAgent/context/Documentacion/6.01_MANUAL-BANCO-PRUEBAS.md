Este manual —documento vivo, nunca se cierra— centraliza todas las pruebas verificables del
daemon BOS. Cada prueba tiene DOS formas de ejecución obligatorias: Vía 1 (bosctl CLI sobre
WebSocket) y Vía 2 (JSON-RPC 2.0 directo sobre Unix socket). Cubre:

- Comandos bosctl (23+ subcomandos)
- Métodos JSON-RPC (50+ métodos)
- Instalación de fichas (install, repair, remove, update)
- Sagas de tenants (deploy, suspend, remove)
- Bootstrap verify (C-01 a C-14)
- Context Plane (device.register, promote, switch, invalidate)
- Seguridad (auth, rate limiting, sanitización)
- Observabilidad (métricas, health checks, watchdog)

**Regla obligatoria:** cada átomo completado que afecte un comando o comportamiento del BOS
actualiza este documento en el mismo commit. Este manual nunca pasa a ✅ — es permanentemente
