## 1. Diagnosis
Clasifica ERROR_FISICO (disco/red/CPU) vs ERROR_LOGICO (config/deps). Determina causa raíz.

## 2. Repair — 3 reintentos
Timeout 10min. 3 reintentos → ERROR_NO_CORREGIBLE → HITL. `bosctl ficha repair <name>`.

## 3. Rollback — restaurar N-1
Backup pre-update. Si update falla → restaurar versión anterior estable.

## 4. Cleanup — cero residuos
Elimina pods, PVCs, configs, secretos. Sistema vuelve a PENDIENTE. TODO(F9): verificar contra K8s API.
