## 1. Servicios systemd

bNexus comprende dos binarios con ciclos de vida independientes:

| Binario | Servicio systemd | Tipo | Usuario | Inicio |
|---------|-----------------|------|---------|--------|
| bhnexus | `bhnexus.service` (system) | `Type=notify` | `bhnexus` | En el servidor central |
| banexus | `banexus.service` (--user) | `Type=notify` | `banexus` | En cada workstation/POS/gateway |

### 1.1 bhnexus.service

```ini
# /etc/systemd/system/bhnexus.service
[Unit]
Description=SBOS Nexus Host — broker central de conectividad física
Documentation=https://skull.bo/sbos/bhnexus
After=network.target bauth.service
Requires=bauth.service
ConditionPathExists=/etc/bos/tls/bhnexus.crt

[Service]
Type=notify
User=bhnexus
Group=bos-group
ExecStart=/opt/bhnexus/bhnexus --config /etc/bhnexus/bhnexus.toml
ExecReload=/bin/kill -HUP $MAINPID
Restart=on-failure
RestartSec=5s
TimeoutStartSec=30s
TimeoutStopSec=30s
WatchdogSec=60s

# Hardening
NoNewPrivileges=true
PrivateTmp=true
ProtectSystem=strict
ProtectHome=true
AmbientCapabilities=CAP_SYS_RAWIO
CapabilityBoundingSet=CAP_SYS_RAWIO
RestrictNamespaces=true
SystemCallFilter=@system-service
ReadWritePaths=/run/bos /var/lib/bhnexus /var/log/bhnexus

[Install]
WantedBy=multi-user.target
```

### 1.2 banexus.service (--user)

```ini
# /etc/systemd/user/banexus.service
[Unit]
Description=SBOS Nexus Agent — agente de borde, workstation/POS/gateway
Documentation=https://skull.bo/sbos/banexus
After=network-online.target

[Service]
Type=notify
ExecStart=/opt/banexus/banexus --config /etc/banexus/banexus.toml
Restart=on-failure
RestartSec=10s
# Código 99 = integridad comprometida — NO reiniciar automáticamente
RestartPreventExitStatus=99
TimeoutStartSec=30s
WatchdogSec=90s

NoNewPrivileges=true
# CAP_BPF + CAP_PERFMON solo para zonas sl=4 (audit_method=ebpf)
AmbientCapabilities=CAP_SYS_RAWIO
CapabilityBoundingSet=CAP_SYS_RAWIO CAP_BPF CAP_PERFMON

[Install]
WantedBy=default.target
```

### 1.3 Secuencia de arranque

```
1. bauth.service arranca → abre /run/bos/bauth.sock y /run/bos/bauth-nexus.sock
2. bhnexus.service arranca:
   a. Lee bhnexus.toml
   b. Verifica TLS cert válido
   c. Conecta a /run/bos/bauth.sock (sub-canal A)
   d. Se conecta como cliente a /run/bos/bauth-nexus.sock (sub-canal B)
   e. Inicializa drivers HAL (OSDP, MQTT, ONVIF)
   f. Abre socket WebSocket TCP 9444 (Puerta 1)
   g. Abre socket JSON-RPC /run/bos/bhnexus.sock (Interface Dual)
   h. Inicia servidor Prometheus en puerto 9445
   i. sd_notify("READY=1")
3. banexus.service arranca (en workstation):
   a. Lee banexus.toml
   b. verify_integrity() del propio binario
   c. Conecta mTLS a wss://bhnexus-host:9444/ws (Puerta 1)
   d. Descarga policy snapshot si cache expirado
   e. Inicia Integrity Monitor (hilo independiente)
   f. Inicia Input Hooking (udev + libusb)
   g. Registra pam_banexus.so en stack PAM
   h. sd_notify("READY=1")
```

## 2. Configuración completa — bhnexus.toml

```toml
# /etc/bhnexus/bhnexus.toml
# Configuración completa de bhnexus — SBOS Nexus Host

[server]
# Puerto Puerta 1: WebSocket mTLS banexus ↔ bhnexus
websocket_port = 9444

# Puerto métricas Prometheus
metrics_port = 9445

# Certificados mTLS (firmados por CA SBOS en Vault)
tls_cert = "/etc/bos/tls/bhnexus.crt"
tls_key  = "/etc/bos/tls/bhnexus.key"
tls_ca   = "/etc/bos/tls/ca.crt"

# Socket Interface Dual (ADR-020)
unix_socket = "/run/bos/bhnexus.sock"
unix_socket_group = "bos-group"
unix_socket_mode  = "0660"

[auth]
# Sub-canal A: consultas de bitmask a bAuth
bauth_socket      = "/run/bos/bauth.sock"
bauth_timeout_ms  = 1000
bauth_retry_count = 3

# Sub-canal B: canal privilegiado (bhnexus lo crea, bAuth conecta)
bauth_privileged_socket = "/run/bos/bauth-nexus.sock"

# Cache de autorización en memoria
cache_ttl_seconds = 30
cache_max_entries = 10000   # ~15MB RAM para 10K entradas SAM-128

[hardware]
# OSDP: habilitado por defecto para lectores de acceso físico
osdp_enabled = true

# MQTT: broker local (Redis no sustituye a MQTT para IoT)
mqtt_enabled = true
mqtt_broker  = "localhost:1883"
mqtt_tls     = true
mqtt_client_cert = "/etc/bos/tls/bhnexus-mqtt.crt"
mqtt_client_key  = "/etc/bos/tls/bhnexus-mqtt.key"

# ONVIF: cámaras IP — habilitado bajo demanda
onvif_enabled = false

# HAL: anti-replay
hal_bloom_filter_size = 10000
hal_bloom_window_seconds = 60

[agents]
# Registro de nodos en SBOSDB (idn_identity_entity, entity_type='banexus_node')
# NO se usan archivos nodes.yml — la identidad vive en la BD soberana
heartbeat_interval_seconds = 30
max_idle_seconds = 300   # nodo sin heartbeat > 5 min → node_offline event
reconnect_window_seconds = 60   # ventana para reconexión con mismo node_id

[metrics]
prometheus_enabled = true
# Prometheus scrape en http://bhnexus-host:9445/metrics

[logging]
level = "info"   # trace | debug | info | warn | error
format = "json"  # json | text
syslog_enabled = true
syslog_facility = "local0"
wazuh_host = "localhost"
wazuh_port = 514
```

## 3. Configuración completa — banexus.toml

```toml
# /etc/banexus/banexus.toml
# Configuración completa de banexus — SBOS Nexus Agent

[agent]
# Identificador único del nodo en idn_identity_entity
node_id = "Ventas-01"

# URL del bhnexus al que conectar (Puerta 1)
host_url = "wss://sbos-server:9444"

# Certificados mTLS del nodo (firmados por CA SBOS en Vault)
# SPIFFE ID: spiffe://sbos.skull/agent/banexus/Ventas-01
tls_cert = "/etc/banexus/tls/agent.crt"
tls_key  = "/etc/banexus/tls/agent.key"
tls_ca   = "/etc/banexus/tls/ca.crt"

[input_hooking]
enabled = true

# Lectores USB a interceptar (VID:PID)
[[input_hooking.readers]]
name       = "honeywell-xenon-1900"
vid        = "0c2e"
pid        = "0007"
type       = "qr"
device_id  = "PHY_DEV_QR_VENTAS_01"

[[input_hooking.readers]]
name       = "acr122u-nfc"
vid        = "072f"
pid        = "2200"
type       = "nfc"
device_id  = "PHY_DEV_NFC_CAJA_01"

[input_hooking.anti_replay]
bloom_filter_size   = 10000
window_seconds      = 60

[input_hooking.timing]
max_processing_delay_s = 5

[shell_sentinel]
enabled = true

# Socket para comunicación con pam_banexus.so
pam_socket     = "/run/banexus/pam.sock"
pam_timeout_ms = 5000
fail_open      = false   # OBLIGATORIO fail-secure

# Método de auditoría de comandos
# "ld_preload" para zonas sl < 4; "ebpf" para sl = 4
audit_method = "ld_preload"

[shell_sentinel.risk_commands]
intercept_critical = true
log_high           = true
log_medium         = true

[actuators]
# Configuración de actuadores locales (relé, buzzer)
relay_port      = "/dev/ttyUSB0"
relay_baud_rate = 9600

[[actuators.devices]]
id       = "RELAY_LOCAL_01"
type     = "gpio_relay"
gpio_pin = 17
active_high = true

[cache]
enabled               = true
max_entries           = 100
# La clave se deriva de la clave privada mTLS (HKDF-SHA256)
encryption_key_source = "mtls_cert"
cache_file_path       = "/var/lib/banexus/policy_cache.enc"
ttl_hours             = 4

[offline]
# Acción por defecto cuando el cache expira y no hay conexión
default_action = "deny_all"

# Aplicaciones que pueden operar sin auth en modo offline
# (solo para workstations con caso de uso específico, no para acceso físico)
offline_allowed_apps = []

# Backoff exponencial de reconexión (segundos)
reconnect_backoff_seconds = [1, 5, 15, 30, 60]

[integrity]
enabled           = true
check_interval_s  = 300   # 5 minutos
binary_path       = "/opt/banexus/banexus"
hash_path         = "/etc/banexus/banexus.sha256"
sig_path          = "/etc/banexus/banexus.sha256.sig"
vault_ca_pem      = "/etc/banexus/vault_ca.pem"
auto_shutdown     = true   # si false: alerta pero no se apaga (NO recomendado)

[logging]
level = "info"
format = "json"
syslog_enabled   = true
syslog_facility  = "SECURITY"
wazuh_integration = true
```

## 4. Métricas Prometheus de bhnexus

bhnexus expone métricas en formato OpenMetrics en `http://bhnexus-host:9445/metrics`.

| Métrica | Tipo | Descripción |
|---------|------|-------------|
| `bhnexus_agents_connected` | Gauge | Nodos banexus conectados actualmente |
| `bhnexus_auth_requests_total` | Counter | Total de auth_requests procesadas (labels: `result=granted/denied/error`) |
| `bhnexus_auth_cache_hits_ratio` | Gauge | Ratio de cache hits (0.0-1.0) en ventana 60s |
| `bhnexus_bauth_latency_ms` | Histogram | Latencia de consultas a bAuth en sub-canal A (percentiles p50/p95/p99) |
| `bhnexus_hardware_devices_online` | Gauge | Dispositivos físicos online (labels: `protocol=osdp/mqtt/onvif/wiegand`) |
| `bhnexus_policy_updates_sent` | Counter | Invalidaciones de cache enviadas a nodos (labels: `reason=emergency_revoke/policy_sync/roltemplate_hash`) |

### 4.1 Métricas adicionales de banexus

banexus no expone Prometheus directamente — sus métricas se consolidan vía bhnexus usando el heartbeat:

| Campo heartbeat | Equivale a |
|----------------|------------|
| `active_sessions` | Gauge de sesiones PAM activas |
| `cache_entries` | Gauge de entradas en policy cache |
| `integrity_ok` | Gauge binario (1=OK, 0=alerta) |
| `uptime_seconds` | Counter de tiempo en operación |

### 4.2 Alertas Wazuh de bhnexus

| Regla NEXUS | Condición | Severidad | Acción automática |
|-------------|-----------|:---------:|-------------------|
| NEXUS-001 | >10 auth denied/min desde mismo nodo | HIGH | Log + SIEM |
| NEXUS-002 | Nodo sin heartbeat >30 min | MEDIUM | Notificar admin |
| NEXUS-003 | Certificado mTLS inválido o no registrado | HIGH | Rechazar + SIEM |
| NEXUS-004 | Error de hardware >5 veces en 5 min | HIGH | Notificar + log |
| NEXUS-005 | Modo offline fail-secure en zona crítica | CRITICAL | Notificar inmediato |
| NEXUS-006 | Versión banexus desactualizada | LOW | Log |
| NEXUS-007 | Heartbeat con uptime reiniciado sospechoso | MEDIUM | SIEM |
| NEXUS-008 | Actuador ejecutado sin auth_request previo | CRITICAL | SIEM + alerta inmediata |

## 5. Comandos de operación habituales

### 5.1 Estado del servicio

```bash
# Estado de bhnexus
systemctl status bhnexus.service

# Estado de banexus (en workstation, como usuario banexus)
systemctl --user status banexus.service

# Logs recientes de bhnexus
journalctl -u bhnexus.service -n 100 --no-pager

# Logs de banexus con ctx_id
journalctl --user -u banexus.service -n 100 --no-pager | jq '.ctx_id, .msg'
```

### 5.2 Reload de configuración

```bash
# Recargar bhnexus sin reiniciar (SIGHUP)
systemctl reload bhnexus.service

# Reiniciar completo (requiere breve downtime)
systemctl restart bhnexus.service
```

### 5.3 Verificación de métricas

```bash
# Ver todas las métricas Prometheus
curl -s http://localhost:9445/metrics | grep bhnexus_

# Ver solo agentes conectados
curl -s http://localhost:9445/metrics | grep bhnexus_agents_connected

# Ver latencia p99 hacia bAuth
curl -s http://localhost:9445/metrics | grep 'bhnexus_bauth_latency_ms.*quantile="0.99"'
```

### 5.4 Verificación del sub-canal B

```bash
# Verificar que el socket privilegiado existe y tiene los permisos correctos
ls -la /run/bos/bauth-nexus.sock
# Esperado: srwxrw---- bhnexus bos-group ... /run/bos/bauth-nexus.sock

# Verificar que bAuth está conectado al sub-canal B
ss -xp | grep bauth-nexus
```

## 6. Troubleshooting frecuente

| Síntoma | Causa probable | Diagnóstico | Solución |
|---------|---------------|-------------|---------|
| `bhnexus: bAuth socket timeout` | bAuth caído o sobrecargado | `systemctl status bauth.service` | Reiniciar bauth, verificar SBOSDB |
| `banexus: certificate expired` | Certificado mTLS del nodo caducado | `openssl x509 -in /etc/banexus/tls/agent.crt -noout -dates` | bOS renueva el cert via Vault PKI |
| `NEXUS-008: actuator without auth` | Bug en código o ataque | Revisar logs del ctx_id específico | Investigación de seguridad |
| `banexus: process::exit(99)` | Integrity Monitor detectó hash mismatch | `journalctl --user -u banexus.service -n 50` | Restaurar binario + nuevo hash firmado |
| `bhnexus: OSDP device offline` | Lector sin alimentación o cable RS-485 cortado | `bnexusctl device list --status=offline` | Verificar cableado y alimentación |
