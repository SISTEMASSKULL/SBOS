## PARTE I — CLI y Unix Socket

### §1 Cómo se levanta bi18n

bi18n arranca como **unidad systemd de tipo `notify`**. Al iniciar, el daemon:

1. Carga `/etc/bos/bi18n.toml` (o la ruta en `$BI18N_CONFIG`)
2. Lee todos los archivos `country-rules/*.toml`
3. Carga los `locales/*.ftl` en el FluentBundle
4. Abre `/run/bos/bi18n.sock` (0660, grupo `bosagent`)
5. Abre `/run/bos/bi18n-grpc.sock`
6. Abre TCP `127.0.0.1:9454` (WebSocket)
7. Envía `sd_notify("READY=1")` — en ese momento systemd marca la unidad como `active`

```bash
# Ver si está activo:
systemctl is-active bi18nd        # → active | inactive | failed

# Estado detallado (PID, socket, últimas líneas de log):
systemctl status bi18nd

# Iniciar:
systemctl start bi18nd

# Ver logs en tiempo real:
journalctl -u bi18nd -f

# Prueba mínima desde CLI:
bi18nctl estado
# Salida esperada: status: ok | versión: X.Y.Z | países cargados: 3
```

#### 1.1 Configuración — bi18n.toml

```toml
# /etc/bos/bi18n.toml — archivo de configuración del daemon

[regional]
locale   = "es-BO"
timezone = "America/La_Paz"
currency = "BOB"
country  = "BO"

[servidor]
socket_path        = "/run/bos/bi18n.sock"
grpc_socket_path   = "/run/bos/bi18n-grpc.sock"
ws_bind            = "127.0.0.1:9454"
ws_rate_limit_rps  = 100          # máx. requests/segundo por IP en WebSocket
ws_timeout_ms      = 5000         # timeout de respuesta WebSocket (ms)
drain_timeout_secs = 30           # espera al hacer graceful shutdown

[rutas]
country_rules_dir = "/etc/bos/bi18n/country-rules"
fluent_dir        = "/etc/bos/bi18n/locales"

[log]
level  = "info"    # trace | debug | info | warn | error
format = "json"    # json | pretty
```

**Variables de entorno (sobreescriben el TOML):**

| Variable | Efecto |
|---|---|
| `BI18N_CONFIG` | Ruta alternativa al archivo TOML |
| `BI18N_SOCKET` | Ruta alternativa al socket Unix (útil en desarrollo) |
| `RUST_LOG` | Nivel de log (sobreescribe `[log].level`) |
| `NOTIFY_SOCKET` | Socket de systemd — gestionado automáticamente por systemd |

#### 1.2 Señales POSIX

| Señal | Efecto |
|---|---|
| `SIGHUP` | Recarga `country-rules/*.toml` + FluentBundle sin reiniciar. Swap atómico. |
| `SIGTERM` | Graceful shutdown: drena peticiones en vuelo (hasta `drain_timeout_secs`). |
| `SIGINT` | Equivalente a `SIGTERM` en desarrollo. |

```bash
# Recargar configuración sin reiniciar:
systemctl reload bi18nd
# Por kill directo:
kill -HUP "$(systemctl show bi18nd --property MainPID --value)"
```

### §2 bi18nctl — Guía completa

`bi18nctl` es el cliente CLI canónico. Se comunica con el daemon por socket Unix.

#### 2.1 Sintaxis y flags globales

```
bi18nctl [FLAGS] <SUBCOMANDO> [ARGUMENTOS]

FLAGS GLOBALES:
  --socket <ruta>     Socket Unix (default: /run/bos/bi18n.sock)
  --json              Imprime JSON crudo (para scripts y CI/CD)
  --quiet             Sin output; exit code: 0=ok, 1=inválido, 2=error
  --ctx-id <uuid>     ctx_id explícito (default: UUID v4 auto-generado)
```

#### 2.2 Referencia de subcomandos

##### `estado` — salud del daemon
```bash
bi18nctl estado
# → status: ok | versión: 0.1.0 | países cargados: 3

bi18nctl --json estado
# → {"status":"ok","version":"0.1.0","paises_cargados":3}
```

##### `recargar` — recargar config completa (country-rules + FTL)
```bash
bi18nctl recargar
# → Recargado. Países: 3 | country_rules: ok | fluent: ok
```

##### `recargar-traducciones` — recargar solo archivos FTL
```bash
bi18nctl recargar-traducciones
# Swap atómico — cero tiempo de parada.
# Rollback automático si hay errores de sintaxis FTL.
```

##### `format-fecha` — formatear fecha ISO
```bash
bi18nctl format-fecha "2026-07-18T14:30:00Z" --locale es-BO --granularidad SoloFecha
# → "18 de julio de 2026"

bi18nctl format-fecha "2026-07-18T14:30:00Z" --locale en-US --granularidad FechaHora
# → "July 18, 2026 at 2:30 PM"
```

##### `format-numero` — formatear número decimal
```bash
bi18nctl format-numero 1234567.89 --locale es-BO --decimales 2
# → "1,234,567.89"
```

##### `format-monto` — formatear monto monetario
```bash
bi18nctl format-monto 1234.56 --moneda BOB --locale es-BO
# → "Bs. 1,234.56"
```

##### `validar-id` — validar documento de identidad
```bash
bi18nctl validar-id "7654321-LP" --tipo CI --pais BO
# → ✓ Válido | normalizado: 7654321-LP

bi18nctl validar-id "abc123" --tipo CI --pais BO
# → ✗ Inválido | error: Cédula de identidad boliviana inválida.

bi18nctl --quiet validar-id "7654321-LP" --tipo CI --pais BO
echo $?   # 0=válido  1=inválido  2=error de protocolo
```

##### `validar-email` — validar dirección de email
```bash
bi18nctl validar-email "usuario@empresa.com"
# → ✓ Válido | normalizado: usuario@empresa.com

bi18nctl --json validar-email "no-es-email"
# → {"valid":false,"normalized":"","errores":["Email inválido..."]}
```

##### `validar-telefono` — validar teléfono
```bash
bi18nctl validar-telefono "+59171234567"
bi18nctl validar-telefono "71234567" --pais BO
# → ✓ Válido | E.164: +59171234567
```

##### `mask-valor` — enmascarar un valor
```bash
bi18nctl mask-valor "7654321-LP" --estrategia parcial
# → ****321-LP
bi18nctl mask-valor "7654321-LP" --estrategia completa
# → **********
```

##### `mask-pii` — enmascarar PII en texto libre
```bash
bi18nctl mask-pii "Contactar a juan@empresa.com o al +59171234567"
# → Contactar a [EMAIL] o al [TELEFONO]
```

##### `locale-resolver` — resolver locale de un tenant
```bash
bi18nctl locale-resolver --tenant empresa-sa --sucursal norte --usuario usr-42
# → locale: es-BO | timezone: America/La_Paz | moneda: BOB | fuente: default
```

##### `enum-display` — mostrar etiqueta localizada de enum
```bash
bi18nctl enum-display ESTADO_CIVIL CASADO --locale es-BO
# → "Casado/a"
```

##### `snapshot` — snapshot de configuración regional
```bash
bi18nctl snapshot --tenant empresa-sa
# Imprime: locale, timezone, currency, separadores, documentos disponibles, enums
```

##### `attr-pipeline` — pipeline validar + formatear + enmascarar
```bash
bi18nctl attr-pipeline ci_numero "7654321-lp" --tenant empresa-sa
# → válido: true | transformado: 7654321-LP | enmascarado: ****321-LP
```

##### `translations check-parity` — verificar paridad FTL (sin daemon)
```bash
# Opera sobre el sistema de archivos — no necesita el daemon activo:
bi18nctl translations check-parity --reference es-BO --locales-dir locales/

# Para CI/CD — falla con exit 1 si faltan claves:
bi18nctl translations check-parity --reference es-BO --locales-dir locales/ --fail-on-missing

# Salida JSON para pipelines:
bi18nctl --json translations check-parity --reference es-BO --locales-dir locales/
```

### §3 Unix Socket — JSON-RPC 2.0 directo

Para daemons SBOS que necesitan invocar bi18n sin pasar por la CLI.

#### 3.1 Protocolo de línea

```
connect("/run/bos/bi18n.sock")
write(JSON_LINE + "\n")
read_line()   → JSON_LINE + "\n"
close()
```

Una conexión por llamada (stateless). El servidor lee una línea JSON, procesa y responde con una línea JSON.

#### 3.2 Prueba manual con socat

```bash
# Llamada simple:
echo '{"jsonrpc":"2.0","id":1,"method":"bi18n.health.check","params":{"ctx_id":"test-001"}}' \
  | socat - UNIX-CONNECT:/run/bos/bi18n.sock

# Con formato jq:
echo '{"jsonrpc":"2.0","id":1,"method":"bi18n.format.date","params":{"ctx_id":"t-001","iso_datetime":"2026-07-18T14:00:00Z","locale":"es-BO","granularity":"SoloFecha","timezone":"America/La_Paz"}}' \
  | socat - UNIX-CONNECT:/run/bos/bi18n.sock | jq .result.display
```

#### 3.3 Desde Rust (cliente de daemon)

```rust
use std::io::{BufRead, BufReader, Write};
use std::os::unix::net::UnixStream;
use serde_json::{json, Value};
use uuid::Uuid;

/// Invoca un método bi18n sobre el socket Unix.
/// Una conexión por llamada — conectar, enviar, leer, cerrar.
pub fn bi18n_llamar(metodo: &str, params: Value) -> Result<Value, Box<dyn std::error::Error>> {
    let socket = std::env::var("BI18N_SOCKET")
        .unwrap_or_else(|_| "/run/bos/bi18n.sock".to_string());

    let mut params_ctx = params;
    params_ctx["ctx_id"] = json!(Uuid::new_v4().to_string());

    let request = serde_json::to_string(&json!({
        "jsonrpc": "2.0",
        "id": 1,
        "method": metodo,
        "params": params_ctx,
    }))? + "\n";

    let mut stream = UnixStream::connect(&socket)?;
    stream.write_all(request.as_bytes())?;
    stream.shutdown(std::net::Shutdown::Write)?;

    let reader = BufReader::new(&stream);
    let linea = reader.lines().next()
        .ok_or("bi18n: sin respuesta del daemon")??;

    let resp: Value = serde_json::from_str(&linea)?;
    if let Some(err) = resp.get("error") {
        return Err(format!("bi18n error: {}", err["message"]).into());
    }
    Ok(resp["result"].clone())
}

// Uso desde bAuth:
pub fn validar_ci(ci: &str) -> Result<bool, Box<dyn std::error::Error>> {
    let r = bi18n_llamar("bi18n.validate.national_id", json!({
        "value": ci, "kind": "CI", "country": "BO"
    }))?;
    Ok(r["valid"].as_bool().unwrap_or(false))
}
```

#### 3.4 Desde Go

```go
package bi18n

import (
    "bufio"
    "encoding/json"
    "fmt"
    "net"
    "os"

    "github.com/google/uuid"
)

func socketPath() string {
    if p := os.Getenv("BI18N_SOCKET"); p != "" {
        return p
    }
    return "/run/bos/bi18n.sock"
}

// Llamar invoca un método bi18n y devuelve el resultado.
func Llamar(metodo string, params map[string]any) (map[string]any, error) {
    params["ctx_id"] = uuid.New().String()

    req, _ := json.Marshal(map[string]any{
        "jsonrpc": "2.0", "id": 1,
        "method": metodo, "params": params,
    })

    conn, err := net.Dial("unix", socketPath())
    if err != nil {
        return nil, fmt.Errorf("bi18n: conexión fallida: %w", err)
    }
    defer conn.Close()

    fmt.Fprintf(conn, "%s\n", req)

    var resp map[string]any
    if err := json.NewDecoder(bufio.NewReader(conn)).Decode(&resp); err != nil {
        return nil, fmt.Errorf("bi18n: error al leer respuesta: %w", err)
    }
    if e, ok := resp["error"].(map[string]any); ok {
        return nil, fmt.Errorf("bi18n: %s", e["message"])
    }
    return resp["result"].(map[string]any), nil
}

// FormatearFecha es un helper de conveniencia.
func FormatearFecha(iso, locale, granularidad string) (string, error) {
    r, err := Llamar("bi18n.format.date", map[string]any{
        "iso_datetime": iso, "locale": locale,
        "granularity": granularidad, "timezone": "America/La_Paz",
    })
    if err != nil {
        return "", err
    }
    return r["display"].(string), nil
}
```

#### 3.5 Desde Python

```python
import json, socket, uuid, os

_SOCKET = os.environ.get("BI18N_SOCKET", "/run/bos/bi18n.sock")

def bi18n_llamar(metodo: str, **params) -> dict:
    """Invoca un método bi18n via socket Unix. Lanza RuntimeError en error RPC."""
    params["ctx_id"] = str(uuid.uuid4())
    request = json.dumps({
        "jsonrpc": "2.0", "id": 1,
        "method": metodo, "params": params,
    }).encode() + b"\n"

    sock = socket.socket(socket.AF_UNIX, socket.SOCK_STREAM)
    sock.connect(_SOCKET)
    try:
        sock.sendall(request)
        sock.shutdown(socket.SHUT_WR)
        datos = b""
        while chunk := sock.recv(4096):
            datos += chunk
    finally:
        sock.close()

    resp = json.loads(datos)
    if "error" in resp:
        raise RuntimeError(f"bi18n: {resp['error']['message']}")
    return resp["result"]

# Helpers de conveniencia:
def validar_email(email: str) -> bool:
    return bi18n_llamar("bi18n.validate.email", value=email)["valid"]

def formatear_monto(monto: str, moneda: str = "BOB") -> str:
    return bi18n_llamar("bi18n.format.money",
        amount=monto, currency_code=moneda, locale="es-BO", country="BO")["display"]
```

### §4 Protocolo WebSocket

bi18n expone un servidor WebSocket en `ws://127.0.0.1:9454`.

```
Acceso interno (servidor): ws://127.0.0.1:9454
Acceso externo (Kong):     wss://api.tudominio.com/bi18n
```

#### 4.1 Ciclo de vida de la conexión

```
CLIENTE                                    SERVIDOR bi18n
  │── WebSocket handshake ─────────────────────>│
  │<─ HTTP 101 Switching Protocols ─────────────│
  │                                              │
  │── JSON-RPC request ────────────────────────>│  (una línea JSON)
  │<─ JSON-RPC response ────────────────────────│  (una línea JSON)
  │                                              │
  │     ... múltiples llamadas por la misma conexión ...
  │                                              │
  │<─ push event (sin id) ──────────────────────│  translations.updated
  │                                              │
  │── WebSocket close ─────────────────────────>│
```

La conexión WebSocket es **persistente durante toda la sesión** — a diferencia del socket Unix, NO se abre/cierra por cada llamada.

#### 4.2 Formatos de mensaje

**Request:**
```json
{
  "jsonrpc": "2.0",
  "id": 42,
  "method": "bi18n.<namespace>.<accion>",
  "params": { "ctx_id": "<uuid-v4>", "<param>": "<valor>" }
}
```

**Respuesta exitosa:**
```json
{ "jsonrpc": "2.0", "id": 42, "result": { "<campo>": "<valor>" } }
```

**Error:**
```json
{ "jsonrpc": "2.0", "id": 42, "error": { "code": -32602, "message": "ctx_id ausente o vacío" } }
```

**Push event (sin `id` — emitido por el servidor):**
```json
{ "event": "translations.updated", "locale": "es-BO", "timestamp": "2026-07-18T14:00:00Z" }
```

#### 4.3 Códigos de error

| Código | Significado |
|---|---|
| `-32700` | JSON malformado |
| `-32600` | Request inválido (falta `jsonrpc`, `method` o `params`) |
| `-32601` | Método no encontrado |
| `-32602` | Parámetro inválido (incluye `ctx_id` ausente o vacío) |
| `-32603` | Error interno del servidor |
| `-32000` | Rate limit superado (solo WebSocket) |
| `-32001` | Timeout de respuesta (solo WebSocket) |

#### 4.4 Límites del servidor

| Parámetro | Default | Configurable en |
|---|---|---|
| Máx. requests/segundo por IP | 100 | `ws_rate_limit_rps` en bi18n.toml |
| Timeout de respuesta | 5000 ms | `ws_timeout_ms` |
| Tamaño máximo de mensaje | 1 MB | interno |

### §5 ctx_id — identificador de contexto (obligatorio en toda llamada)

**Toda llamada bi18n debe incluir `ctx_id`** — un UUID v4 que identifica la operación de negocio.
Se genera UNA VEZ por operación (no por llamada individual) para correlacionar logs en múltiples servicios.

```typescript
// JavaScript / TypeScript
const ctxId = crypto.randomUUID();
// Con librería uuid: import { v4 as uuid } from "uuid"; const ctxId = uuid();
```
```dart
// Dart / Flutter
import 'package:uuid/uuid.dart';
final ctxId = const Uuid().v4();
```
```python
# Python
import uuid; ctx_id = str(uuid.uuid4())
```
```go
// Go
import "github.com/google/uuid"; ctxID := uuid.New().String()
```
```rust
// Rust
use uuid::Uuid; let ctx_id = Uuid::new_v4().to_string();
```

**Patrón correcto (un ctx_id por operación de negocio):**
```typescript
async function guardarEmpleado(datos: DatosEmpleado) {
    const ctx = crypto.randomUUID();   // UN solo ctx_id

    const [email, telefono, ci] = await Promise.all([
        bi18n.call("bi18n.validate.email_html5", { ctx_id: ctx, value: datos.email }),
        bi18n.call("bi18n.phone.parse_e164",     { ctx_id: ctx, number: datos.telefono }),
        bi18n.call("bi18n.attr.pipeline",         { ctx_id: ctx, field_id: "ci_numero", value: datos.ci }),
    ]);
}
```

### §6 Cliente TypeScript / JavaScript

```typescript
import { v4 as uuid } from "uuid";

type RpcResult = Record<string, unknown>;
type PushEvent = { event: string; locale?: string; timestamp?: string };
type PushCb    = (e: PushEvent) => void;

/**
 * Cliente WebSocket persistente para el daemon bi18n.
 * Gestiona reconexión automática y distribución de push events.
 */
export class Bi18nClient {
    private ws: WebSocket | null = null;
    private pending = new Map<number, { ok: (r: RpcResult) => void; err: (e: Error) => void }>();
    private counter = 1;
    private pushCbs: PushCb[] = [];
    private reconectando = false;

    constructor(private readonly url = "ws://127.0.0.1:9454") {
        this.conectar();
    }

    private conectar(): void {
        this.ws = new WebSocket(this.url);

        this.ws.onopen = () => { this.reconectando = false; };

        this.ws.onmessage = ({ data }: MessageEvent) => {
            const msg = JSON.parse(data as string);
            if (msg.event !== undefined) {
                this.pushCbs.forEach(cb => cb(msg as PushEvent));
                return;
            }
            const entry = this.pending.get(msg.id as number);
            if (!entry) return;
            this.pending.delete(msg.id as number);
            msg.error
                ? entry.err(new Error(`[${msg.error.code}] ${msg.error.message}`))
                : entry.ok(msg.result as RpcResult);
        };

        this.ws.onclose = () => {
            if (!this.reconectando) {
                this.reconectando = true;
                setTimeout(() => this.conectar(), 3000);
            }
        };
    }

    /** Invoca un método bi18n y retorna una promesa con el resultado. */
    call(metodo: string, params: Record<string, unknown> = {}): Promise<RpcResult> {
        return new Promise((ok, err) => {
            if (this.ws?.readyState !== WebSocket.OPEN) {
                err(new Error("bi18n: WebSocket no conectado"));
                return;
            }
            const id = this.counter++;
            this.pending.set(id, { ok, err });
            this.ws!.send(JSON.stringify({
                jsonrpc: "2.0", id, method: metodo,
                params: { ctx_id: uuid(), ...params },
            }));
        });
    }

    /** Registra un callback para push events del servidor. */
    onPush(cb: PushCb): void { this.pushCbs.push(cb); }

    cerrar(): void { this.ws?.close(); }
}

// ─── Bundle Prefetch ──────────────────────────────────────────────────────────

/**
 * Descarga el namespace de traducciones al login y lo sirve localmente.
 * Cero llamadas de red en tiempo de render. Se actualiza vía push event.
 */
export class GestorTraducciones {
    private bundle: Record<string, string> = {};
    private localeActual = "es-BO";
    private nsActual     = "ui.general";

    constructor(private readonly bi18n: Bi18nClient) {
        this.bi18n.onPush(async ({ event }) => {
            if (event === "translations.updated") {
                await this.cargar(this.localeActual, this.nsActual);
            }
        });
    }

    async cargar(locale: string, namespace: string): Promise<void> {
        this.localeActual = locale;
        this.nsActual = namespace;
        const r = await this.bi18n.call("bi18n.translate.bundle",
            { ctx_id: uuid(), locale, namespace });
        this.bundle = r.bundle as Record<string, string>;
    }

    /** Resuelve clave del bundle local — cero llamadas de red. */
    t(clave: string, fallback?: string): string {
        return this.bundle[clave] ?? fallback ?? clave;
    }
}

// ─── Inicialización (al login del usuario) ───────────────────────────────────

const bi18n = new Bi18nClient();
const i18n  = new GestorTraducciones(bi18n);

// Una sola llamada descarga el namespace completo:
await i18n.cargar("es-BO", "ui.empleados");

// En cada componente — cero llamadas de red:
console.log(i18n.t("boton-guardar"));   // "Guardar"
console.log(i18n.t("titulo-modulo"));   // "Gestión de Empleados"
```

### §8 Cliente Dart / Flutter

```dart
import 'dart:async';
import 'dart:convert';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:web_socket_channel/web_socket_channel.dart';
import 'package:uuid/uuid.dart';

const _uuid = Uuid();

/// Cliente WebSocket bi18n con reconexión automática y push events.
class Bi18nClient {
  static const _url = 'ws://127.0.0.1:9454';

  WebSocketChannel? _channel;
  final Map<int, Completer<Map<String, dynamic>>> _pendientes = {};
  final List<void Function(Map<String, dynamic>)> _pushCbs = [];
  int _counter = 1;

  Bi18nClient() { _conectar(); }

  void _conectar() {
    _channel = WebSocketChannel.connect(Uri.parse(_url));
    _channel!.stream.listen(
      _onMsg,
      onDone: () => Future.delayed(const Duration(seconds: 3), _conectar),
    );
  }

  void _onMsg(dynamic raw) {
    final data = jsonDecode(raw as String) as Map<String, dynamic>;
    if (data.containsKey('event')) {
      for (final cb in _pushCbs) cb(data);
      return;
    }
    final id = data['id'] as int?;
    final c = id != null ? _pendientes.remove(id) : null;
    if (c == null) return;
    data.containsKey('error')
        ? c.completeError(Exception(data['error']['message']))
        : c.complete(data['result'] as Map<String, dynamic>);
  }

  Future<Map<String, dynamic>> call(
      String metodo, [Map<String, dynamic> params = const {}]) {
    final id = _counter++;
    final c = Completer<Map<String, dynamic>>();
    _pendientes[id] = c;
    _channel!.sink.add(jsonEncode({
      'jsonrpc': '2.0', 'id': id, 'method': metodo,
      'params': {'ctx_id': _uuid.v4(), ...params},
    }));
    return c.future;
  }

  void onPush(void Function(Map<String, dynamic>) cb) => _pushCbs.add(cb);
  void cerrar() => _channel?.sink.close();
}

// Provider Riverpod global:
final bi18nProvider = Provider<Bi18nClient>((_) => Bi18nClient());

// Uso en widget:
class FechaDisplay extends ConsumerWidget {
  final String isoDate;
  const FechaDisplay(this.isoDate, {super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final bi18n = ref.read(bi18nProvider);
    return FutureBuilder<Map<String, dynamic>>(
      future: bi18n.call('bi18n.format.date', {
        'iso_datetime': isoDate, 'locale': 'es-BO',
        'granularity': 'SoloFecha', 'timezone': 'America/La_Paz',
      }),
      builder: (_, snap) => Text(snap.data?['display'] as String? ?? '...'),
    );
  }
}
```

### §9 Cliente Python (asyncio)

```python
import asyncio, json, uuid as uuid_lib
from typing import Any, Callable
import websockets


class Bi18nAsyncClient:
    """Cliente WebSocket asíncrono con reconexión automática y push events."""

    def __init__(self, url: str = "ws://127.0.0.1:9454"):
        self.url = url
        self._ws = None
        self._pendientes: dict[int, asyncio.Future] = {}
        self._push_cbs: list[Callable] = []
        self._id = 0
        self._tarea: asyncio.Task | None = None

    async def conectar(self) -> None:
        self._ws = await websockets.connect(self.url)
        self._tarea = asyncio.create_task(self._escuchar())

    async def _escuchar(self) -> None:
        try:
            async for msg in self._ws:
                data = json.loads(msg)
                if "event" in data:
                    for cb in self._push_cbs:
                        asyncio.create_task(cb(data))
                    continue
                fut = self._pendientes.pop(data.get("id"), None)
                if fut:
                    if "error" in data:
                        fut.set_exception(RuntimeError(data["error"]["message"]))
                    else:
                        fut.set_result(data["result"])
        except websockets.ConnectionClosed:
            await asyncio.sleep(3)
            await self.conectar()

    async def call(self, metodo: str, **params: Any) -> dict:
        self._id += 1
        msg_id = self._id
        params["ctx_id"] = str(uuid_lib.uuid4())
        fut: asyncio.Future = asyncio.get_event_loop().create_future()
        self._pendientes[msg_id] = fut
        await self._ws.send(json.dumps({
            "jsonrpc": "2.0", "id": msg_id,
            "method": metodo, "params": params,
        }))
        return await fut

    def on_push(self, cb: Callable) -> None:
        self._push_cbs.append(cb)

    async def cerrar(self) -> None:
        if self._tarea:
            self._tarea.cancel()
        if self._ws:
            await self._ws.close()


async def main():
    bi18n = Bi18nAsyncClient()
    await bi18n.conectar()
    r = await bi18n.call("bi18n.format.money",
        amount="1234.56", currency_code="BOB", locale="es-BO", country="BO")
    print(r["display"])   # Bs. 1,234.56
    await bi18n.cerrar()
```

### §10 Cliente Go (WebSocket)

```go
package bi18nws

import (
    "encoding/json"
    "fmt"
    "sync"
    "sync/atomic"

    "github.com/google/uuid"
    "github.com/gorilla/websocket"
)

// ClienteWs es un cliente WebSocket persistente para bi18n.
type ClienteWs struct {
    conn       *websocket.Conn
    mu         sync.Mutex
    pendientes sync.Map
    counter    atomic.Int64
    url        string
    onPushFn   func(map[string]any)
}

func NuevoCliente(url string) (*ClienteWs, error) {
    c := &ClienteWs{url: url}
    return c, c.conectar()
}

func (c *ClienteWs) conectar() error {
    c.mu.Lock()
    defer c.mu.Unlock()
    conn, _, err := websocket.DefaultDialer.Dial(c.url, nil)
    if err != nil {
        return fmt.Errorf("bi18n: %w", err)
    }
    c.conn = conn
    go c.escuchar()
    return nil
}

func (c *ClienteWs) escuchar() {
    for {
        _, msg, err := c.conn.ReadMessage()
        if err != nil {
            _ = c.conectar()
            return
        }
        var data map[string]any
        if json.Unmarshal(msg, &data) != nil {
            continue
        }
        if _, ok := data["event"]; ok {
            if c.onPushFn != nil {
                c.onPushFn(data)
            }
            continue
        }
        id := int64(data["id"].(float64))
        if ch, ok := c.pendientes.LoadAndDelete(id); ok {
            ch.(chan map[string]any) <- data
        }
    }
}

// Llamar invoca un método bi18n y espera la respuesta.
func (c *ClienteWs) Llamar(metodo string, params map[string]any) (map[string]any, error) {
    id := c.counter.Add(1)
    params["ctx_id"] = uuid.New().String()

    ch := make(chan map[string]any, 1)
    c.pendientes.Store(id, ch)

    req, _ := json.Marshal(map[string]any{
        "jsonrpc": "2.0", "id": id,
        "method": metodo, "params": params,
    })
    c.mu.Lock()
    err := c.conn.WriteMessage(websocket.TextMessage, req)
    c.mu.Unlock()
    if err != nil {
        return nil, fmt.Errorf("bi18n: %w", err)
    }

    resp := <-ch
    if e, ok := resp["error"].(map[string]any); ok {
        return nil, fmt.Errorf("bi18n: %s", e["message"])
    }
    return resp["result"].(map[string]any), nil
}

func (c *ClienteWs) OnPush(fn func(map[string]any)) { c.onPushFn = fn }
```

### §11 El SDK — Por qué y cómo

**El problema:** un campo CI requería ~40 líneas de boilerplate (llamadas RPC explícitas a
`validate`, `format`, `mask`). Un formulario de 10 campos sumaba ~400 líneas. El código UI
tenía hardcodeada la lógica de validación.

**La solución:** el **Bi18nSdk** (Capa 2) encapsula esa complejidad. El cliente solo declara
en un **JSON config** qué tipo de dato es el campo. El daemon bi18n decide cómo validarlo,
formatearlo y enmascararlo.

```
┌────────────────────────────────────────────────────────────────┐
│  Capa 3 — Adaptadores  (Vue · React · Flutter · PyQt6) ~30 ln │
├────────────────────────────────────────────────────────────────┤
│  Capa 2 — Bi18nSdk  (API bSet/bUnSet · DOM · eventos) ~200 ln │
├────────────────────────────────────────────────────────────────┤
│  Capa 1 — Bi18nClient  (WebSocket · JSON-RPC · reconexión)    │
│           ← ya implementada en §6 de la Parte II              │
└────────────────────────────────────────────────────────────────┘
```

**Principio fundamental:** el JSON es el medio. El SDK y el CLI son dos formas distintas de
entregar el mismo JSON al mismo motor Rust. Lo que pasa en CLI pasa idéntico en SDK.

```bash
# CLI — mismo JSON, mismo motor
bi18nctl validate '{ "base": "CI", "pais": "BO", "value": "7654321-LP", "ctx_id": "t-1" }'

# SDK — mismo JSON, mismo motor
bi18n.campo("#ci").tipo({ base: "CI", pais: "BO" }).bSet()
```

**Cómo usar el SDK TypeScript:**
Los archivos del SDK viven en `sdk/ts/` del repositorio bi18n. No existe paquete publicado —
bi18n es agnóstico de lenguaje. El programador copia o referencia los archivos localmente:

```
sdk/ts/bi18n-tipos.ts    ← interfaces TypeScript
sdk/ts/bi18n-client.ts   ← cliente WebSocket JSON-RPC
sdk/ts/bi18n-vinculo.ts  ← VinculoImpl (IMask + eventos)
sdk/ts/bi18n-sdk.ts      ← Bi18nSdk fachada pública
```

Cualquier lenguaje puede integrar bi18n directamente via WebSocket JSON-RPC — sin paquete,
sin instalación, solo conectar al socket y enviar JSON.

### §12 API de valor — `.valor(raw)`

Transforma un valor crudo: aplica formato, máscara de visualización o validación.
La cadena es lazy: solo `.obtener()` ejecuta las llamadas al daemon.

```javascript
import { Bi18nSdk } from './bi18n-sdk.js'  // archivo local de sdk/ts/
const bi18n = new Bi18nSdk() // conecta a ws://127.0.0.1:9454

// Formato de fecha
const fecha = await bi18n.valor("2026-07-18").formato("date:long").obtener()
// → "18 de julio de 2026"

// Formato de monto
const monto = await bi18n.valor(1250.50).formato("money:BOB").obtener()
// → "Bs. 1.250,50"

// Teléfono: formato display + máscara de censura
const tel = await bi18n.valor("71234567")
                        .tipo({ base: "phone", pais: "BO" })
                        .formato("phone:national:BO")
                        .mascara_display("partial:3")
                        .obtener()
// → "7 ***-4567"

// Validar sin binding de DOM (retorna resultado directo)
const resultado = await bi18n.valor("7654321-LP")
                              .tipo({ base: "CI", pais: "BO" })
                              .validar()
// → { valido: true, errores: [], normalizado: "7654321-LP" }
```

### §13 Vínculo de campo — `.campo(selector).tipo({...}).bSet()`

Vincula un campo de formulario al daemon: aplica máscara de entrada, valida al perder el foco,
emite eventos por estado (`onValid`, `onInvalid`, `onWarn`, `onError`).

`tipo()` **siempre recibe un JSON** — sin strings DSL. `bSet()` activa el vínculo y retorna
un `Vinculo`. Cuando el componente se destruye, llamar `vinculo.bUnSet()`.

```javascript
// Mínimo — solo CI Bolivia
const v = bi18n.campo("#ci")
  .tipo({ base: "CI", pais: "BO", requerido: true, msgError: "CI inválida" })
  .bSet()

// Con todos los eventos
const v = bi18n.campo("#fecha-nac")
  .tipo({
    base: "date",
    min_fecha: "hoy-100a", max_fecha: "hoy-18a",
    requerido: true,
    msgError: "Debe ser mayor de 18 años"
  })
  .bSet()
  .onValid  (r  => marcar("#fecha-nac", "verde",    r.mensaje))
  .onWarn   (r  => marcar("#fecha-nac", "amarillo", r.mensaje))
  .onInvalid(r  => marcar("#fecha-nac", "rojo",     r.mensaje))
  .onError  (e  => mostrarAlerta("bi18n no disponible: " + e.message))

// Email con verificación DNS MX
const v = bi18n.campo("#email")
  .tipo({
    base: "email", requerido: true,
    verificar_mx: true, detectar_typo: true, rechazar_temporal: true,
    msgOk: "Correo verificado", msgError: "Correo inválido"
  })
  .bSet()
  .onValid  (r => marcar("#email", "verde", r.mensaje))
  .onInvalid(r => marcar("#email", "rojo",  r.mensaje))

// Monto con rango y advertencia
const v = bi18n.campo("#salario")
  .tipo({
    base: "money", moneda: "BOB", min: 2362, max: 50000,
    msgOk: "Monto válido",
    msgWarn: "Monto cercano al límite — se requiere aprobación",
    msgError: "El monto debe estar entre Bs. 2.362 y Bs. 50.000"
  })
  .bSet()
  .onValid  (r => marcar("#salario", "verde",    r.mensaje))
  .onWarn   (r => marcar("#salario", "amarillo", r.mensaje))
  .onInvalid(r => marcar("#salario", "rojo",     r.mensaje))

// Contraseña + confirmación (validación cruzada)
bi18n.campo("#password").tipo({ base: "password", requerido: true,
  msgOk: "Contraseña válida", msgError: "Mínimo 8 caracteres" }).bSet()

bi18n.campo("#password-conf").tipo({
  base: "password", confirmar: "#password",
  msgOk: "Las contraseñas coinciden", msgError: "Las contraseñas no coinciden"
}).bSet()
  .onValid  (r => marcar("#password-conf", "verde", r.mensaje))
  .onInvalid(r => marcar("#password-conf", "rojo",  r.mensaje))

// Destruir al salir del componente
v.bUnSet()
```

**Interface `Vinculo` completa:**

```typescript
interface ResultadoValidacion {
  valido:            boolean;
  valor_normalizado: string;
  mensaje:           string;    // msgOk | msgWarn | msgError
  errores:           string[];
  metadata:          Record<string, unknown>;
}
interface Vinculo {
  bUnSet(): void;
  onValid  (cb: (r: ResultadoValidacion) => void): Vinculo;  // chainable
  onInvalid(cb: (r: ResultadoValidacion) => void): Vinculo;
  onWarn   (cb: (r: ResultadoValidacion) => void): Vinculo;
  onError  (cb: (e: Error)              => void): Vinculo;
  readonly valor: string;
}
```

**Ciclo UX — cuándo valida el SDK:**

| Evento | Acción |
|---|---|
| `input` / keystroke | Solo aplica máscara de entrada — sin errores al escribir |
| `blur` (1ª vez) | E1-E4 → `onValid` / `onInvalid` / `onWarn` |
| `blur` + E5 aplica | E5 con debounce 800 ms → evento al completar |
| `input` (campo con error) | Re-valida → feedback positivo al corregir |
| campo `confirmar` | Valida cruzada inmediatamente al escribir |
| `submit` | E1-E5 en todos los campos — muestra todos los errores |

### §14 Vínculo de formulario — `.formulario(selector, schema)`

```dart
  @override State<Bi18nCampo> createState() => _Bi18nCampoState();

  }
  @override void dispose() { _vinculo?.bUnSet(); super.dispose(); }
  @override Widget build(BuildContext context) => TextField(
    controller: widget.controller,
    decoration: InputDecoration(
      errorText:   _estado == 'invalid' ? _mensaje : null,
      helperText:  _estado == 'valid'   ? _mensaje : null,
    ));
}
```

#### PyQt6

```python
# Uso: campo = Bi18nCampo(parent, tipo_config={"base": "phone", "pais": "BO"})
from PyQt6.QtWidgets import QWidget, QLineEdit, QLabel, QVBoxLayout
from bi18n_sdk import Bi18nSdk

class Bi18nCampo(QWidget):
    def __init__(self, parent=None, tipo_config=None):
        super().__init__(parent)
        self.input = QLineEdit(self)
        self.msg_label = QLabel("", self)
        QVBoxLayout(self).addWidgets([self.input, self.msg_label])
        self._vinculo = (Bi18nSdk().campo(self.input)
            .tipo(tipo_config or {"base": "text"})
            .b_set()
            .on_valid  (lambda r: self.msg_label.setText(r["mensaje"]))
            .on_invalid(lambda r: self.msg_label.setText(r["mensaje"]))
            .on_warn   (lambda r: self.msg_label.setText(r["mensaje"])))

    def closeEvent(self, e):
        if self._vinculo: self._vinculo.b_unset()
        super().closeEvent(e)
```

### §18 Máscaras de visualización

Controlan cómo se muestra un valor ya almacenado. Se usan con `.mostrar()` o con la
cadena `.valor().mascara_display()`.

```javascript
// Censura parcial — muestra los últimos N caracteres
bi18n.valor("1234567-LP").mascara_display("partial:2").obtener()  // → "****-**LP"

// Censura total
bi18n.valor("mi-contraseña").mascara_display("full").obtener()    // → "•••••••••••••"

// Formato legible (para display en UI)
bi18n.valor("71234567")
     .tipo({ base: "phone", pais: "BO" })
     .mascara_display("format:phone:national:BO")
     .obtener()                                                    // → "7 123-4567"

// Normalización a E.164 (para almacenamiento)
bi18n.valor("71234567")
     .tipo({ base: "phone", pais: "BO" })
     .mascara_display("e164")
     .obtener()                                                    // → "+59171234567"
```

> **Distinción clave:** máscara de entrada = guía al usuario mientras escribe (activa con `bSet()`);
> máscara de visualización = controla cómo se muestra un valor almacenado (activa con `.mostrar()` o `.valor()`).
> Especificación completa: [A.19 §5](anexos/A.19_ANEXO-SDK-BI18N-UI-v1.0.md)

## Apéndice B — Errores frecuentes y soluciones

| Error | Causa | Solución |
|---|---|---|
| `ctx_id ausente o vacío` | Llamada sin `ctx_id` | Siempre incluir `ctx_id: generarUuid()` |
| `método no encontrado` | Typo en el nombre del método | Verificar en A.10; formato `bi18n.<ns>.<accion>` |
| Connection refused | Daemon no activo | `systemctl start bi18nd` |
| `result.valid = false` sin error RPC | Valor de dominio inválido | Leer `result.errores[]` o `result.validation_errors[]` |
| Timeout 5s en WebSocket | Daemon sobrecargado | `bi18nctl estado`; revisar `journalctl -u bi18nd` |
| Push event no llega | Cliente desconectado | Implementar reconexión automática (§6) |
| `-32000` rate limit superado | > 100 req/s por IP | Usar Bundle Prefetch; ajustar `ws_rate_limit_rps` |
