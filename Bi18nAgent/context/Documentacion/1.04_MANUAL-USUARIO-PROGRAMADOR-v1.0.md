# 1.04 — Manual del Usuario Programador — bi18n

**Versión:** 1.0.0
**Fecha:** 2026-07-18
**Público:** programadores que consumen el daemon bi18n desde cualquier lenguaje (Dart/Flutter, TypeScript, Python, Go, etc.).
**Prerequisito:** tener acceso al WebSocket `ws://127.0.0.1:9454` o al socket Unix `/run/bos/bi18n.sock`.
**Protocolo:** JSON-RPC 2.0 sobre WebSocket TCP (recomendado para GUI/frontend) o Unix socket (recomendado para daemons/backend).
**Inventario completo de métodos:** [A.10 — Inventario API Librerías](anexos/A.10_INVENTARIO-API-LIBRERIAS-v3.0.md)

## §1 Conceptos fundamentales

### 1.1 ¿Qué es bi18n?

**bi18n** (i18n-orchestrator) es un **daemon soberano** del ecosistema SBOS que provee servicios de internacionalización, formateo, validación y enmascaramiento de datos. No es una librería — es un proceso del sistema que corre siempre en segundo plano y se invoca mediante llamadas de red.

Ventajas respecto a incluir librerías directamente en cada aplicación:
- Reglas actualizadas sin recompilar ni redesplegar las apps
- Un único punto de verdad para formatos regionales (moneda, fecha, número)
- Auditoría centralizada de todas las operaciones de datos
- Soporte nativo para los 37 dominios del ecosistema SBOS

### 1.2 ctx_id — identificador de contexto (SBOS-049)

**Toda llamada a bi18n debe incluir un `ctx_id`** — un identificador de traza de la operación. Se genera una vez por operación de negocio (no por llamada individual) y permite:
- Correlacionar logs de múltiples servicios para una misma operación
- Auditar quién hizo qué y cuándo (ISO 27001 A.8.15)
- Distribuir la traza en observabilidad (OpenTelemetry)

```javascript
// Ejemplo: generar ctx_id (UUIDv4 en cualquier lenguaje)
const ctxId = crypto.randomUUID();   // JavaScript
const ctx_id = str(uuid.uuid4())     # Python
let ctx_id = Uuid::new_v4().to_string();  // Rust
String ctxId = UUID.randomUUID().toString(); // Java/Dart
```

### 1.3 Transporte recomendado

| Cliente | Transporte recomendado | Puerto/ruta |
|---|---|---|
| GUI / frontend web | WebSocket | `ws://127.0.0.1:9454` |
| Aplicación desktop (Flutter) | WebSocket | `ws://127.0.0.1:9454` |
| Daemon SBOS (Rust, Go) | Unix socket (JSON-RPC) | `/run/bos/bi18n.sock` |
| Script bash / CI | `bi18nctl` o `socat` | socket o CLI |

## §2 Patrón de uso básico (WebSocket)

### 2.1 Ciclo de vida de la conexión WebSocket

```
1. Abrir conexión WebSocket → ws://127.0.0.1:9454
2. En login del usuario: descargar bundle de traducciones (Bundle Prefetch)
3. Durante la sesión: invocar métodos según necesidad
4. Escuchar eventos push: si llega "translations.updated", refrescar bundle
5. Al cerrar la app: cerrar conexión
```

### 2.2 Estructura del request JSON-RPC 2.0

```json
{
  "jsonrpc": "2.0",
  "id": 42,
  "method": "bi18n.<namespace>.<método>",
  "params": {
    "ctx_id": "<uuid-de-la-operacion>",
    "<param1>": "<valor1>"
  }
}
```

### 2.3 Estructura de la respuesta exitosa

```json
{
  "jsonrpc": "2.0",
  "id": 42,
  "result": {
    "<campo>": "<valor>"
  }
}
```

### 2.4 Estructura del error

```json
{
  "jsonrpc": "2.0",
  "id": 42,
  "error": {
    "code": -32602,
    "message": "ctx_id ausente o vacío"
  }
}
```

**Códigos de error JSON-RPC:**
| Código | Significado |
|---|---|
| -32700 | JSON malformado |
| -32600 | Request inválido (falta "method" o "jsonrpc") |
| -32601 | Método no encontrado |
| -32602 | Parámetro inválido (incluye ctx_id ausente) |
| -32603 | Error interno del servidor |

## §3 Bundle Prefetch — traducciones en login (patrón recomendado)

El patrón más eficiente para apps GUI: **descargar todas las traducciones al inicio** y renderizar localmente sin llamadas de red por componente.

```javascript
// Al hacer login, una sola llamada descarga el namespace completo:
async function cargarTraduccionesAlLogin(locale, namespace) {
  const resp = await ws.call({
    method: "bi18n.translate.bundle",
    params: { ctx_id: generarCtxId(), locale, namespace }
  });
  // resp.result.bundle = { "boton-guardar": "Guardar", "titulo-app": "SBOS", ... }
  // Almacenar en memoria:
  window.__bi18n_bundle = resp.result.bundle;
}

// En cada componente — CERO llamadas de red:
function t(key) {
  return window.__bi18n_bundle[key] ?? key;
}
```

### 3.1 Actualización automática con push events

Cuando el administrador actualiza las traducciones en producción, bi18n emite un evento push a todos los clientes conectados:

```javascript
ws.onmessage = (msg) => {
  const data = JSON.parse(msg.data);

  // Respuesta a una llamada RPC:
  if (data.id !== undefined) {
    pendingCalls.get(data.id)?.resolve(data);
    return;
  }

  // Evento push sin id:
  if (data.event === "translations.updated") {
    // Refrescar el bundle con el mismo locale actual
    cargarTraduccionesAlLogin(localeActual, namespaceActual);
  }
};
```

## §5 Ejemplos de código por lenguaje

### 5.1 JavaScript / TypeScript

```typescript
class Bi18nClient {
  private ws: WebSocket;
  private pending = new Map<number, (r: any) => void>();
  private idCounter = 1;

  constructor(url = "ws://127.0.0.1:9454") {
    this.ws = new WebSocket(url);
    this.ws.onmessage = (e) => {
      const data = JSON.parse(e.data);
      // Evento push (sin id)
      if (data.event === "translations.updated") {
        this.emit("translations_updated", data);
        return;
      }
      // Respuesta a RPC
      if (data.id !== undefined) {
        const resolve = this.pending.get(data.id);
        if (resolve) { resolve(data); this.pending.delete(data.id); }
      }
    };
  }

  call(method: string, params: object): Promise<any> {
    const id = this.idCounter++;
    const ctx_id = crypto.randomUUID();
    return new Promise((resolve, reject) => {
      this.pending.set(id, (resp) => {
        if (resp.error) reject(new Error(resp.error.message));
        else resolve(resp.result);
      });
      this.ws.send(JSON.stringify({ jsonrpc: "2.0", id, method, params: { ctx_id, ...params } }));
    });
  }

  emit(event: string, data: any) { /* ... tu sistema de eventos ... */ }
}

// Uso:
const bi18n = new Bi18nClient();
const fecha = await bi18n.call("bi18n.format.date_icu", {
  iso: "2026-07-18T14:30:00Z",
  locale: "es-BO",
  style: "long"
});
console.log(fecha.display); // "18 de julio de 2026"
```

### 5.2 Dart / Flutter

```dart
import 'dart:convert';
import 'dart:math';
import 'package:web_socket_channel/web_socket_channel.dart';

class Bi18nClient {
  final WebSocketChannel _channel;
  final Map<int, Completer<Map<String, dynamic>>> _pending = {};
  int _idCounter = 1;

  Bi18nClient() : _channel = WebSocketChannel.connect(
    Uri.parse('ws://127.0.0.1:9454'),
  ) {
    _channel.stream.listen(_onMessage);
  }

  void _onMessage(dynamic message) {
    final data = jsonDecode(message as String) as Map<String, dynamic>;
    // Evento push
    if (data.containsKey('event')) {
      // manejar traducciones actualizadas
      return;
    }
    final id = data['id'] as int?;
    if (id != null && _pending.containsKey(id)) {
      if (data.containsKey('error')) {
        _pending[id]!.completeError(data['error']['message']);
      } else {
        _pending[id]!.complete(data['result'] as Map<String, dynamic>);
      }
      _pending.remove(id);
    }
  }

  Future<Map<String, dynamic>> call(String method, Map<String, dynamic> params) {
    final id = _idCounter++;
    final ctxId = _generateUuid();
    final completer = Completer<Map<String, dynamic>>();
    _pending[id] = completer;
    _channel.sink.add(jsonEncode({
      'jsonrpc': '2.0',
      'id': id,
      'method': method,
      'params': {'ctx_id': ctxId, ...params},
    }));
    return completer.future;
  }

  String _generateUuid() {
    final rng = Random.secure();
    final bytes = List<int>.generate(16, (_) => rng.nextInt(256));
    // Formato UUID v4 simplificado
    bytes[6] = (bytes[6] & 0x0f) | 0x40;
    bytes[8] = (bytes[8] & 0x3f) | 0x80;
    return bytes.map((b) => b.toRadixString(16).padLeft(2, '0')).join()
      .replaceRange(8, 8, '-').replaceRange(13, 13, '-')
      .replaceRange(18, 18, '-').replaceRange(23, 23, '-');
  }

  void dispose() => _channel.sink.close();
}

// Uso en Widget:
final bi18n = Bi18nClient();
final result = await bi18n.call('bi18n.format.date_icu', {
  'iso': '2026-07-18T14:30:00Z',
  'locale': 'es-BO',
  'style': 'long',
});
print(result['display']); // "18 de julio de 2026"
```

### 5.3 Python

```python
import asyncio
import json
import uuid
import websockets

class Bi18nClient:
    def __init__(self, url="ws://127.0.0.1:9454"):
        self.url = url
        self._ws = None
        self._pending = {}
        self._id = 0

    async def connect(self):
        self._ws = await websockets.connect(self.url)
        asyncio.create_task(self._listener())

    async def _listener(self):
        async for msg in self._ws:
            data = json.loads(msg)
            if "event" in data:
                # push event
                continue
            msg_id = data.get("id")
            if msg_id in self._pending:
                self._pending[msg_id].set_result(data)
                del self._pending[msg_id]

    async def call(self, method: str, **params):
        self._id += 1
        msg_id = self._id
        ctx_id = str(uuid.uuid4())
        fut = asyncio.get_event_loop().create_future()
        self._pending[msg_id] = fut
        await self._ws.send(json.dumps({
            "jsonrpc": "2.0",
            "id": msg_id,
            "method": method,
            "params": {"ctx_id": ctx_id, **params},
        }))
        resp = await fut
        if "error" in resp:
            raise RuntimeError(resp["error"]["message"])
        return resp["result"]

# Uso:
async def main():
    client = Bi18nClient()
    await client.connect()
    result = await client.call(
        "bi18n.format.date_icu",
        iso="2026-07-18T14:30:00Z",
        locale="es-BO",
        style="long"
    )
    print(result["display"])  # "18 de julio de 2026"

asyncio.run(main())
```

## §7 Buenas prácticas

### 7.1 Gestión de ctx_id

```javascript
// CORRECTO — un ctx_id por operación de negocio
async function guardarEmpleado(datos) {
  const ctx = generarCtxId();  // UN ctx_id para toda la operación

  // Todos los llamados de esta operación usan el mismo ctx_id
  const email = await bi18n.call("bi18n.validate.email_html5", { ctx_id: ctx, value: datos.email });
  const telefono = await bi18n.call("bi18n.phone.parse_e164", { ctx_id: ctx, number: datos.telefono });
  const ci = await bi18n.call("bi18n.attr.pipeline", { ctx_id: ctx, field_id: "ci_numero", value: datos.ci });
}

// INCORRECTO — no generar un ctx_id nuevo por cada llamada individual
async function validarEmail(email) {
  return bi18n.call("bi18n.validate.email_html5", {
    ctx_id: generarCtxId(),  // ← INCORRECTO: pierde la correlación con la operación padre
    value: email
  });
}
```

### 7.2 Manejo de errores

```typescript
try {
  const result = await bi18n.call("bi18n.validate.email_html5", { value: email });
  if (!result.valid) {
    // Error de dominio (email inválido) — no es un error de red
    mostrarError("Email inválido");
  }
} catch (e) {
  // Error de protocolo (red, daemon caído, ctx_id ausente)
  // Registrar el error y mostrar mensaje genérico al usuario
  console.error("Error al comunicarse con bi18n:", e.message);
  mostrarError("Servicio temporalmente no disponible");
}
```

### 7.3 Bundle Prefetch vs. llamadas individuales

```
Cuándo usar Bundle Prefetch (bi18n.translate.bundle):
✅ Al iniciar la app / al hacer login
✅ Cuando un namespace tiene > 5 mensajes que se usarán en la misma sesión
✅ Para componentes que renderizan muchos textos (listas, tablas, formularios)

Cuándo usar llamadas individuales (bi18n.translate.message):
✅ Para mensajes de error específicos en contextos de excepción
✅ Para mensajes con argumentos dinámicos en tiempo real
✅ Para namespaces de uso muy esporádico (1-2 mensajes en toda la sesión)
```

### 7.4 Reconexión automática en WebSocket

```javascript
function conectarBi18n() {
  const ws = new WebSocket("ws://127.0.0.1:9454");

  ws.onclose = () => {
    console.warn("bi18n desconectado — reintentando en 5s");
    setTimeout(conectarBi18n, 5000);
  };

  ws.onerror = (e) => {
    console.error("Error WebSocket bi18n:", e);
  };

  return ws;
}
```

## §9 Errores comunes y cómo resolverlos

| Error | Causa | Solución |
|---|---|---|
| `ctx_id ausente o vacío` | Olvidar incluir `ctx_id` en los params | Siempre pasar `ctx_id: generarUuid()` |
| `método no encontrado` | Typo en el nombre del método | Verificar en A.10; el formato es `bi18n.<ns>.<método>` |
| `no se pudo conectar` | Daemon bi18nd no activo | `systemctl status bi18nd` |
| `result.valid = false` sin error | Valor inválido según las reglas | Ver `result.errores` o `result.validation_errors` |
| Timeout después de 10s | Daemon sobrecargado o bloqueado | Verificar `bi18nctl estado`; ver logs `journalctl -u bi18nd` |
| Push event no llega | Cliente desconectado o lento | Implementar reconexión automática (§7.4) |
